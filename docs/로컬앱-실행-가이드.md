# 모두봄 로컬 앱 — 실제 자동 서류발급 실행 가이드

> **전략상 위치(중요·정직성)** — 이 로컬 앱은 [무설치-자동화-전략](무설치-자동화-전략.md)을 **대체하지 않는다**.
> 그 문서의 기본 노선은 **무설치**다: **1안 원터치 핸드오프**(전 브라우저·모바일, 인증·제출만 본인 — 이미 배포됨)
> → **2안 공공 마이데이터/전자증명서 API**(사업자 등록 시 "인증만 하면 자동", 목적지). 서버사이드 RPA(3안)는
> 안전상 채택하지 않는다.
> 이 로컬 앱은 그 사이의 **"설치를 감수하면 지금 당장 진짜 끝까지 자동"** 선택지다 — 사용자 PC에서 **본인의 브라우저·본인
> 인증**으로만 도는 로컬 RPA라 3안(서버가 세션·개인정보 보유)의 위험이 없다. 심사·데모에서 **실제 발급까지** 보여줄 때,
> 또는 무설치 핸드오프가 번거로운 사용자를 위한 보완재로 쓴다. (본인인증·최종 제출은 여전히 본인이 수행 — 비가역·법적 행위.)


배포된 웹사이트(https://biocode67.github.io/modoo-bom/)는 **추천·검색·챗봇**을 누구나 설치 없이
쓸 수 있습니다. 다만 **자동 서류발급/신청(RPA)** 은 브라우저 보안정책(크롬 Local Network Access)
때문에 "공개 사이트 → 내 PC(localhost)" 호출이 기본 차단됩니다. 그래서 자동발급을 **프롬프트 없이
확실히** 쓰려면, 로컬 에이전트가 프론트까지 **동일 출처(localhost:8000)** 로 직접 서빙하는
**로컬 앱**으로 실행합니다. 동일 출처라 CORS·권한 프롬프트가 전혀 없습니다.

---

## 방법 A — 설치 프로그램(권장, 심사위원·일반인)

`backend/dist/모두봄-설치.exe` 를 **더블클릭 → 설치**하면 시작메뉴·바탕화면에 "모두봄" 아이콘이
생깁니다(관리자 권한 불필요, 사용자 폴더 설치). 아이콘 실행 시:
- 로컬 에이전트가 뜨고(약 1초), 브라우저가 자동으로 `http://localhost:8000/` 을 엽니다.
- 프론트가 실행파일에 번들되어 동일 출처로 서빙 → 자동발급 버튼이 바로 활성화됩니다.
- 서류 자동발급 시 **시스템 Chrome** 이 열리고, 카카오 간편인증은 **본인이 직접**(법적 요구),
  최종 제출도 본인 확인 뒤 진행됩니다(비가역 행위 안전장치).

설치가 부담되면 **`backend/dist/모두봄-에이전트.zip`** 을 풀고 안의 `모두봄-에이전트.exe` 를
더블클릭해도 동일하게 동작합니다(설치 불필요, ~63MB).

> 배포본 빌드: 저장소 루트에서 **`build-installer.bat`** 실행
>   → dist-app 빌드 → PyInstaller 단일 실행파일 → 배포 ZIP → (Inno Setup 있으면) 설치 프로그램.
>   사전: `setup-local.bat` 로 `venv-local` 준비. Inno Setup 설치: `winget install JRSoftware.InnoSetup`.

## 방법 B — 소스에서 실행(개발자)

1. 최초 1회: 저장소 루트에서 **`setup-local.bat`** 더블클릭
   - 경량 venv(`backend/venv-local`) + 로컬 에이전트 의존성 + 프론트 로컬 빌드(`dist-app`) 준비
   - 필요: Python 3.11+, Node.js 20+
2. 이후 실행: **`run-local-app.bat`** 더블클릭
   - 로컬 에이전트(경량 `local_server`) 기동 → 브라우저 자동 오픈

수동 실행:
```bash
cd frontend && npm run build:app         # dist-app 생성(base='/', 동일출처)
cd ../backend
RPA_ENABLED=1 RPA_BROWSER_CHANNEL=chrome python -m uvicorn local_server:app --host 127.0.0.1 --port 8000
# 브라우저에서 http://localhost:8000/ 열기
```

## 구조 요약

| | 배포 웹(gh-pages) | 로컬 앱(localhost:8000) |
|---|---|---|
| 추천·검색·챗봇 | ✅ 클라이언트 엔진 | ✅ 클라이언트 엔진 |
| 자동 서류발급/신청 | ⚠️ 크롬 LNA 권한 허용 필요 | ✅ 동일출처 — 프롬프트 0 |
| 백엔드 | (선택) Render AI | 경량 `local_server`(RPA 전용, 수 초 기동) |

- 프론트 감지: `frontend/src/lib/backend.ts` 가 AI 베이스(클라우드)와 RPA 베이스(로컬)를 분리
  감지해, `capabilities.rpa` 가 true 일 때만 자동발급 UI를 노출합니다.
- 경량 서버 `backend/local_server.py` 는 chromadb/langchain 을 import 하지 않아 즉시 기동되고
  단일 실행파일로 번들됩니다. 클라우드용 풀스택은 기존 `backend/main.py` 를 그대로 씁니다.
