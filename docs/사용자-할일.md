## 🔑 계정·키가 필요한 일 (Claude가 대신 못 함)
- **data.go.kr API 키 발급** → `backend/.env`에 `DATA_GO_KR_SERVICE_KEY=` 입력
  - 이후 개별 데이터셋 "활용신청"(즉시 승인): 중앙부처복지서비스(15090532) 등
  - 키만 있으면 Claude가 ETL 확장으로 수천 건 추가 수집 가능
- **Render(무료) 백엔드 배포** — 심사장에서 챗 "🧠 실시간 AI(Claude)" 라벨을 보여주려면 필요
  - 순서: render.com 가입 → New Web Service → repo 연결 → `backend/` · `uvicorn main:app` → 환경변수 `ANTHROPIC_API_KEY` 입력
  - 배포 URL을 `frontend/.env.production`의 `VITE_API_BASE=`에 넣고 `npm run deploy`
- **크롬 웹스토어 개발자 등록($5) + 확장 제출** — `extension/STORE.md` 절차대로
- (선택) **Supabase 프로젝트 생성** — 로그인·동기화 기능 켜려면 `supabase/SETUP.md`
