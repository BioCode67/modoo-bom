## 계정·키가 필요한 일 (계정 소유자만 가능)
- **(신규·사용자 방향 제시) 서버 RPA용 한국 리전 서버** — "설치 없이 웹에서 바로 발급"의 마지막 조각.
  월 1~2만원대 KR VPS(2GB) 1대. 코드·프라이버시 장치(다운로드 즉시 삭제 등)는 준비 완료,
  상세: `docs/서버RPA-웹발급-설계.md`. 첫 실측은 "그 서버에서 정부24 접속되는지"(해외IP 차단 확인).
- data.go.kr API 키 발급 → `backend/.env`에 `DATA_GO_KR_SERVICE_KEY=` 입력
  - 이후 개별 데이터셋 "활용신청"(즉시 승인): 중앙부처복지서비스(15090532) 등
  - 키만 있으면 ETL 확장으로 수천 건 추가 수집 가능
- ~~Render(무료) 백엔드 배포~~ — 완료·운영 중(modoo-bom.onrender.com, Gemini 2.5 Flash + Groq 폴백, RAG 5,267건).
  main 푸시가 자동 배포되므로 별도 조작 불필요. 키 만료·요금 알림만 가끔 확인.
- (선택) Supabase 프로젝트 생성 — 로그인·동기화 기능 켜려면 `supabase/SETUP.md`
- (선택·우선순위 낮아짐) 크롬 웹스토어 등록($5) — 이제 서류발급 기본 경로가 무설치 전자증명서로 바뀌어(7/6)
  확장은 '고급 자동화 시연'용. 데모는 확장 없이도 완주되므로 웹스토어 등록은 급하지 않음.

## 정부 공식 연계 (프로덕션 로드맵 — 기획서 '향후 계획'에 넣으면 강력)
> 지금 당장 할 필요는 없지만, 기획서에서 "우리는 스크래핑 꼼수가 아니라 정부 공식 유통망과 연계한다"로
> 제시하면 심사에서 성숙도가 크게 올라감. 실제 이용신청은 대회 이후.
- 전자증명서 API 연계(`dpaper.kr`) — 발급 서류를 전자문서로 제3자(모두봄) 제출. API 이용신청서를 운영부서에
  공문·우편 접수 → API KEY·지갑주소 발급. (개인 제출형이라 우리 '개인정보 온디바이스' 원칙과 잘 맞음)
- 공공 마이데이터 이용기관 등록(`adm.mydata.go.kr`) — 본인 동의로 주민등록·과세증명 등 249종을 API 수신.
  이용기관 신청서·이용환경 조사표 등 서류 접수 필요(기관/사업자 등록 전제라 대회용은 로드맵으로).
