# 오늘 새 기능 테스트 가이드 (7/17~19) — 데스크탑앱 10분 코스

> 최근 배포분(Deploy #22~#107)의 **새 기능만** 빠르게 눌러보는 체크리스트.
> 전체 데모 대본은 `docs/청년월세-데모-시나리오.md`.

## 0. 준비 (2분)
```bat
git pull
run-local-app.bat        :: 저장소 '루트'에서 더블클릭 — HEAD 바뀌었으니 자동 재빌드 후 실행
```
- 앱이 열리면 분석 → **청년월세지원 담기** → **나의 복지** 로 이동.
- 상단 🤖 스트립에 **`내 PC 에이전트 연결됨 v0.3.2`** 가 보여야 오늘 빌드예요(낮은 버전이면 재빌드 안 된 것 — 콘솔 로그 확인).

## 1. 🩺 [발급 전 점검] — 리허설 자동화 (1분)
- 스트립의 **[발급 전 점검]** 클릭 → 5항목 체크리스트(자동화 브라우저·정부24 연결·복지로 연결·발급 폴더·디스크).
- **기대**: 집/사무실 회선이면 전부 ✓ → "모두 정상 — 발급 준비 완료". 실패 항목이 있으면 항목별 원인이 그대로 표시.

## 2. 🔊 인증 음성 안내 토글 (30초)
- 스트립의 **[인증 음성 안내]** 클릭 → 버튼이 초록으로 "켬" 표시(기기에 기억됨).
- 켜두면 3번 테스트에서 인증 차례에 알림음 + **"휴대폰에서 인증 요청을 승인해 주세요"** 음성이 나옵니다.

## 3. 🚀 원클릭 연쇄 — 오늘의 메인 (5분, 카카오 인증 필요)
- 서류 도우미에서 실명·생년월일·휴대폰 입력 → **[🚀 전부 자동발급 + 자동신청까지]** (체크 기본 ON).
- **확인할 것**:
  - 🔑 **(신규) 로그인 인증은 첫 서류 1회만**: 두 번째 서류부터 카드에 **"같은 로그인으로 이어서
    발급해요"**가 뜨고 카카오 로그인 요청이 다시 오지 않아야 정상 — 브라우저 창도 하나만 유지돼요.
    (서류별 전자서명 승인 요청은 정부24 정책상 뜰 수 있음 — 그건 정상)
  - 진행률 바: `n/m 완료 · 지금: ○○` + 인증 차례에 **📱 노란 펄스 배지** + 알림음(+음성)
  - **[⏭ 이 단계 건너뛰기]**: 진행 중 한 번 눌러보세요 — 그 서류만 '중단'되고 **다음 서류로 계속** 가야 정상(전체가 멈추면 버그)
  - 발급 성공한 서류는 카드에 '발급 문서 받기(PDF)' + 자동으로 **발급 완료 기억**(재실행 시 그 서류는 다시 안 뗌)
  - 서류 끝나면 **📨 자동신청 카드**: 복지로 양식 작성·자동첨부 → 완료 문구가 **"신청 양식 준비 완료 — 열린 창에서 확인 후 제출"** ("발급 미완료" 오문구가 나오면 버그)
  - 끝나면 **종결 요약 배너**: "✅ 연쇄 자동발급 끝 — 서류 n건 발급 · n건 건너뜀 · 신청 양식 n건 준비"
    + 배너의 **[🗂 발급물 폴더 열기]** 클릭 → 방금 만들어진 PDF들이 탐색기로 열리는지 (신규)
- 복지로 창에서 **최종 제출은 직접** → 앱의 신청 카드에서 **[✓ 제출까지 마쳤어요]** 클릭 → "신청 완료로 기록" 칩 확인.
- 중간에 **F5 새로고침** 한 번 해보세요 — 돌아오면 진행 상태가 **자동 재연결**돼야 정상.

## 3.3 📞 통화 상담 + 다국어 (1분, 오늘 신규 — 웹/앱 공통)
- 챗봇(우하단) 열고 헤더의 **📞** 클릭 → 통화 화면에서 말(또는 아래 입력칸)로
  **"72세 혼자 사는데 소득이 적어요"** → 그 자리에서 진단 + 음성 브리핑 + [결과 화면 보기].
- 마이크 버튼 **옆 언어 선택**을 🇻🇳 Tiếng Việt로 → 베트남어 인사(음성은 기기에 베트남어 보이스가 있을 때만, 없으면 자막만 — 정상).
- 홈 **외국인 섹션의 📞 Tiếng Việt** 버튼 → 처음부터 베트남어 통화로 시작.
- 통화에 영어로 "housing support" 입력 → 영어 안내 + [See matching programs] → 탐색 AI 검색으로 연결.
- (오늘 신규 2) 분석 결과 화면의 **[📞 전화로 설명 듣기]** → 통화가 열리며 결과를 조목조목 읽어줌 →
  이어서 "첫번째 담아줘" 말로 담기. 통화를 끊고 챗을 열면 **방금 통화 내용이 이어져** 있어야 정상.
- (실PC 확인) 통화 하단 **🎙️ 연속 대화(실험적)** 체크 → 답 낭독이 끝나면 마이크가 자동으로 다시 켜지는지.
  스피커 에코로 오인식이 돌면 체크 해제(무음·권한 오류 시엔 자동으로 꺼짐 — 안전장치).

## 3.4 🧩 서류 커버리지 확장 (2분, 인터넷 필요)
**방법 A — 앱 안에서(신규, 제일 쉬움)**: 나의 복지 → 일괄발급 패널 아래
**[🔎 목록에 없는 서류도 실측으로 추가]** 입력창에 서류명(예: 혼인관계증명서) → [실측 확인].
정부24를 실제 조사해(개인정보 없이) 발급 가능하면 **재시작 없이 바로** 패널·발급 목록에 β로 추가돼요.
미지원 서류 카드의 **[🔎 자동 확인]** 버튼도 같은 동작. 실패는 이유와 함께 정직하게 안내(등록 안 됨).
**방법 B — 원커맨드(여러 종 일괄)**: 저장소 루트의 **`probe-docs.bat --register 혼인관계증명서 기본증명서`**
→ 통과분만 자동 등록, 앱 재시작 후 반영. 기본 후보 11종은 인자 없이 `probe-docs.bat`로 일괄 조사(보고서).
- 새 서류에 **β 배지**(β = 코드·버튼은 실측 확인됨, **첫 발급 완주가 최종 검증**).
- 새 서류로 발급 1회 완주해보기 — 실패하면 `probe-docs.bat --remove 서류명`으로 내리면 끝(정직 설계).
- `--list`로 등록 현황 확인. 이 확장은 내 PC 로컬 파일(`backend/rpa/docs_extra.json`)이라 배포에 안 섞여요.
- **후보 칩·일괄**: 입력창 아래 후보 칩(11종)을 탭하거나 **[🚀 후보 N종 한번에 실측]** — 한 브라우저로
  순회 조사해 통과분만 한꺼번에 β 추가(종당 30초 정도).
- **자동신청도 실측(β)**: 자동신청 버튼이 없는 정책 상세(지자체 제외)의 **[🔎 자동신청 가능한지 실측 확인(β)]**
  → 복지로에서 신청 상세를 실측으로 찾으면 자동신청 버튼이 바로 생겨요. 복지로 특성상 온라인 신청형인지는
  **첫 자동신청 실행**이 최종 검증(방문형이면 정직한 오류 + 공식 링크, 버튼 아래 [등록 해제]).

## 3.5 🔁 인증정보 "이 탭에서는 기억하기" (30초, 신규)
- 인증정보 폼 위의 **[이 탭에서는 기억하기]** 체크 → 이름 입력 → **F5** → 값이 **그대로 복원**돼야 정상
  (체크 안 하면 기존처럼 비워짐 — 기본 OFF·디스크 미저장 설계 유지).
- 체크 **해제** 순간 보관분 즉시 삭제 · **탭을 닫아도** 자동 삭제 · [다음 분 상담 시작]도 함께 삭제.

## 4. 🗂 내 서류함 + 📷 촬영 (2분)
- 임대차계약서 카드 **[📷 촬영]** → 찍고(또는 갤러리) → 제출문서로 만들기 → 서류함에 **'첨부 후보' 배지**로 등록.
- 서류함에서 방금 파일 **삭제(2탭)** · **[저장 폴더 열기]** 동작 확인.

## 4.5 🧾 서류함 지능화 + 준비도 (밤사이 신규, 2분)
- 서류함 항목에 **발급 경과 배지**: 발급 3개월 지난 증명서엔 `⚠️ 3개월 지남`(재발급 권장), 60~90일엔 `유효 확인`.
- **[묶음 받기(ZIP)]**: 서류 종류별 최신 1건씩 ZIP 한 파일 — 복지로 수동 첨부·이메일 제출용. 여정 종결 배너에도 📦 버튼.
- **부족분만 발급**: 서류함에 이미 유효한 서류(예: 등본)가 있으면 🚀 버튼이 **"부족한 서류 n종만 자동발급"**으로 바뀌고
  건너뛰는 목록을 보여줘요. 필요한 자동발급 서류가 **전부** 있으면 **[📨 자동신청만 진행]** 버튼이 떠요.
- 정책 상세의 에이전트 신청에도 **부족 서류 진단**("n종이 아직 서류함에 없어요")이 떠요.

## 4.7 ⭐ 오늘 아침 신규 3종 (10분)
- **🗂 서류 골라 일괄발급**: 서류 도우미의 🚀 버튼 아래 **[지원 15종에서 골라 한번에 발급 →]** 클릭 →
  체크박스로 원하는 서류 선택(담은 정책에 부족한 서류는 기본 선택, 서류함에 있으면 `🗂 있음` 표시) →
  **[🚀 선택한 n종 한번에 발급]** — 담은 정책과 무관한 서류(예: 병적증명서)도 한 번 인증으로 이어서 발급돼요.
- **📷 촬영 업그레이드**: 임대차계약서 [📷 촬영] → 사진을 넣으면
  ① **✂️ 자르기**에 문서 영역이 **자동으로 잡혀** 있어요(어두운 배경에서 — 확인·조정만)
  ② **🖍 가리기**(썸네일 우하단)로 주민번호 뒷자리를 **드래그해 검정으로 덮기** — 픽셀을 실제로
  덮어써 저장되니 파일에 원본 정보가 안 남아요. 신분증·통장사본 제출에 권장.
- **🗂 서류함 그룹핑 + 👁 열람 + 🧹 정리**: 같은 서류를 다시 발급하면 **최신본 1줄만** 보이고 이전본은
  **[▸ 이전 버전 n건 보기]**로 접혀요(묶음 ZIP·자동첨부도 최신본 기준). 각 줄의 **👁**로 파일을
  새 탭에서 바로 확인하고, **[🧹 이전 버전 정리]**로 지난 발급본만 한 번에 지울 수 있어요(최신본 보존).
- **🌱 새싹이 가이드**: 분석·탐색·나의 복지 **왼쪽 아래**에 작은 3D 새싹이가 떠서
  '지금 뭘 하면 되는지' 한 문장으로 안내해요(화면·상태별로 문구가 바뀜). ✕로 접고,
  [다시 보지 않기]로 영구 숨김(이 기기).
- **빈 상태 슬림 모드**: 담은 복지를 **모두 비운 상태**로 나의 복지에 들어가도(첫 사용·심사 동선)
  '서류 발급 도우미'가 떠서 15종 일괄발급·서류함이 그대로 동작해요 — 빈 화면으로 끝나지 않아요.
- 발급 속도: 정부24·복지로 화면 전환 대기가 '준비되면 즉시 진행'으로 바뀌어 **서류당 수 초 빨라져요**
  (느린 회선에서는 기존과 동일 — 대기 상한은 그대로).

## 문제가 생기면
- 스트립 **[진단 복사]** → 붙여넣어 전달해 주세요(개인정보 없음).
- 🔑 연쇄 발급이 이상하면(두 번째 서류부터 로그인이 꼬이는 등): **명령 프롬프트를 열어**
  `set RPA_ONE_LOGIN=0` 입력 → **같은 창에서** `run-local-app.bat` 실행(더블클릭이 아니라 같은 창에서
  실행해야 설정이 전달돼요) — 예전 '서류별 개별 인증' 방식으로 즉시 복귀(코드 수정·재빌드 불필요).
- 개별 서류만 막히면 [⏭ 건너뛰기], 전체가 이상하면 [⏹ 전체 중단] 후 다시 시작 — 데모는 계속 갑니다.

> 지금 게시본은 **app-v0.3.0**(구버전) — 🔑 한 번 인증 연쇄·자동 재시도·서류함(👁/🧹)·📷 자동감지/마스킹·
> 새싹이 가이드가 **없는** exe입니다. 심사위원이 받아볼 수 있으니 v0.3.2로 갱신을 권장해요.

```bat
git pull                     :: 최신 코드
build-installer.bat          :: backend\dist\모두봄-설치.exe + 모두봄-에이전트.zip 생성
cd frontend && npm run e2e:exe && cd ..   :: 실행파일 패키징 스모크(뜨고·서빙·RPA 준비)
publish-release.bat          :: app-v0.3.2 릴리스 생성(--latest) → 홈 CTA 자동 갱신
```
- `publish-release.bat`은 v0.3.2 태그로 미리 맞춰뒀어요(자산 ASCII명 복사 포함). gh CLI 로그인 필요.
- 게시 후 확인: 시크릿 창에서 홈 → [Windows 앱 바로 받기] → 받은 파일 속성에서 버전/크기 확인.
