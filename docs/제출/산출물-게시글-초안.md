## 모두봄 — 몰라서 못 받는 복지를 찾아주는 개인 복지 AI 에이전트

**90초 시연 영상: [유튜브 링크]**

**설치·로그인 없이 지금 바로 체험: https://biocode67.github.io/modoo-bom/**

"72세 혼자 사는데 소득이 적어요" — 이 한마디(음성도 됩니다)면
정부·지자체·민간재단 5,300여 건에서 받을 수 있는 복지를 찾아 금액까지 계산해 드립니다.

직접 확인해보실 수 있는 것들:

1. 홈에서 한 문장 분석 — 위 예시를 그대로 입력해 보세요. 월 최대 수급액이 바로 나옵니다.
2. 챗봇(우하단)에 "다 담아줘" — 대화 맥락을 기억하는 행동형 에이전트입니다.
3. 정책 탐색 → AI 의미 검색 켜기 → "tiền hỗ trợ sinh con"(베트남어) — 브라우저 안에서 도는
   신경망이 자국어 질문을 한국 복지에 의미로 매칭합니다(서버 전송 0).
4. Windows 앱을 설치하면 정부24 서류 발급을 에이전트가 대신합니다 — 폰에서 카카오 '인증 허용'만
   누르면 등본이 바탕화면에 저장됩니다(영상 40초 부분). 본인인증과 최종 제출은 법적 단계라
   의도적으로 사람에게 남겼습니다.

기술: 온디바이스 신경망 임베딩(다국어 하이브리드 검색) · LangGraph 10노드 에이전트 ·
Playwright RPA(실제 정부24) · 클라이언트 복지엔진(2026 공식 선정기준) · PWA.
전부 실데이터·실동작이며, 자동테스트 643개+와 실브라우저 E2E로 검증합니다.

이 서비스는 제출 직전(7/13~14) 실제 복지관에서 어르신들과 함께 실사용 검증을 마쳤습니다.
