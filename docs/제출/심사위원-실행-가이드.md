# 모두봄(ModooBom) — 심사위원 실행 가이드

> 2026 AI·SW중심대학 디지털 경진대회 SW부문 · 본선 산출물 [필수 2) 직접 실행 가능한 데모]의 실행 가이드입니다.
> 개인 복지 자산 관리 AI Agent — 복지 추천부터 **정부24 서류 자동발급·복지로 자동신청**까지.

---

## 0. 한눈 요약 — 실행 경로는 3가지입니다

| 경로 | 준비물 | 시간 | 볼 수 있는 것 |
|---|---|---|---|
| **A. 웹 (설치 없음)** | 브라우저만 | 0분 | 추천·AI 의미검색·📞통화 상담·계산기 등 전 기능(자동발급 제외) |
| **B. 데스크탑 앱 (권장)** | Windows 10/11 | 2분 | A 전부 + **서류 자동발급·자동신청·서류함** (앱의 핵심) |
| **C. 소스 실행 (개발자용)** | Python 3.11+, Node 20+ | 5분 | B와 동일 |

- **A. 웹**: https://biocode67.github.io/modoo-bom/ — 지금 바로 열립니다.
- **B. 데스크탑 앱**: 제출 폴더의 `ModooBom-Setup.exe` 더블클릭(설치형) 또는 `ModooBom-Agent.zip` 압축 해제 후
  `모두봄-에이전트.exe` 더블클릭(무설치). ⚠️ 처음 실행 시 "Windows의 PC 보호" 파란 창이 뜨면
  **[추가 정보] → [실행]** — 코드서명 인증서(유료)를 붙이지 않은 오픈소스 데모라 뜨는 정상 안내입니다.
- **C. 소스**: 저장소 루트에서 `setup-local.bat`(최초 1회) → `run-local-app.bat`. (macOS/Linux는 아래 §5)

앱을 실행하면 **검은 콘솔 창**(에이전트 — 닫으면 종료)이 뜨고 브라우저가 `http://localhost:8000/` 을 자동으로 엽니다.

## 1. 3분 핵심 심사 코스 (데스크탑 앱)

1. **홈** — "말 한마디로 복지 찾기"에 상황을 입력(또는 🎤 음성): 예) `72세 혼자 사는데 소득이 적어요`
   → 즉시 분석·결과 화면(현금성 혜택 합계·TOP3·신뢰 근거).
2. 결과의 새싹이 카드에서 **[🚀 오토파일럿]** 버튼 하나 — 추천 전부 담기 → **나의 복지** 자동 이동 →
   서류 연쇄 발급까지 에이전트가 이어서 진행합니다(인증정보가 비어 있으면 입력칸으로 안내).
   수동으로 하려면 **[담기]** → **나의 복지** 탭 → **서류 준비 도우미**가 필요한 서류를 자동 정리.
3. 🤖 상태 스트립의 **[발급 전 점검]** — 브라우저·정부24/복지로 연결·발급 폴더·디스크·서류함 무결성 6항목을
   실제로 점검해 보여줍니다(실패도 숨기지 않는 정직 설계).
4. **[자동] 버튼**으로 서류 자동발급 — 실명·생년월일·휴대폰 입력 후 시작하면 시스템 Chrome/Edge가 열리고
   정부24 로그인 → 양식 입력까지 자동 진행, **카카오/PASS 간편인증만 심사위원 휴대폰에서 승인**하면
   PDF가 발급돼 🗂 서류함에 저장됩니다. (진행 실화면이 카드에 실시간 표시)
5. **🚀 원클릭 연쇄** — 정책 상세의 에이전트 신청: 필요 서류를 **로그인 인증 1회로 연쇄 발급** → 방금 발급물을
   복지로 신청 양식에 **자동첨부** → 정보 자동입력 → **제출 직전 정지**. 
   ✅ **안전장치: 최종 제출 버튼은 절대 자동으로 누르지 않습니다** — 실제 신청이 접수될 걱정 없이 심사하셔도 됩니다.

## 2. 본인인증 없이 확인 가능한 것 (휴대폰 인증을 원치 않으실 때)

자동발급의 **본인인증은 법적 요구**라 사람이 승인해야 하지만, 아래는 인증 없이 그대로 확인됩니다:

- **[발급 전 점검]**(6항목 실점검) · **[진단 복사]**(개인정보 무포함 기술 진단)
- 자동발급 시작 → 정부24 로그인 화면까지의 **자동 진행 + 진행 실화면**(인증 대기에서 [⏹ 중단] 가능)
- 🗂 **내 서류함**: 📷 서류 촬영 → 자동 보정·민감정보 가리기 → 제출용 PDF 등록 · 무결성(손상 ⚠️) 관리 · 묶음 ZIP
- 🔎 **커버리지 실측 확장**: 서류 이름 하나로 정부24를 실측 조사해 자동발급 목록을 그 자리에서 늘리는 기능
  (후보 칩 11종 [🚀 한번에 실측] · 자동신청도 정책 상세에서 동일) — 조사에는 로그인·개인정보가 쓰이지 않습니다
- **📞 통화형 상담**(말로 묻고 소리로 답) · 온디바이스 다국어 AI 의미검색(🇰🇷🇬🇧🇻🇳🇨🇳) · 급여 계산기 ·
  긴급복지 진단 · 생애주기 시뮬레이터 (웹 A 경로에서도 동일)

## 3. 요구 환경·유의사항

- **Windows 10/11 + Chrome 또는 Edge**(윈도우 선탑재 — 별도 설치 불필요). 관리자 권한 불필요.
  - **기본 브라우저가 Chrome이 아니어도 됩니다.** 자동발급은 앱이 Chrome→Edge 순으로 직접 구동하고
    (둘 다 없을 때만 실패 안내), 앱 화면도 크롬/엣지를 우선 열어 드립니다(없으면 기본 브라우저로 폴백).
- 인터넷 연결 필요(정부24·복지로 실사이트 자동화). 사내망 등에서 정부 사이트가 차단되면
  [발급 전 점검]이 원인을 그대로 보여줍니다.
- 포트 8000 사용 중이면 해당 프로그램 종료 후 재실행해 주세요.
- **개인정보**: 이름·생년월일·연락처는 자동입력을 위해 **심사위원 PC 안에서만** 사용되며 외부 서버로
  전송되지 않습니다. 발급 문서는 `바탕화면\모두봄서류` 폴더에만 저장됩니다(앱의 [새 상담 시작]으로 일괄 삭제 가능).
- LLM API 키 없이도 전 기능이 동작합니다(클라이언트 규칙 엔진 + Mock 모드 — 데모 전제 설계).

## 4. 문제 해결

| 증상 | 조치 |
|---|---|
| 파란 "PC 보호" 창 | [추가 정보] → [실행] (미서명 오픈소스 데모의 정상 안내) |
| 브라우저가 안 열림 | 브라우저에서 `http://localhost:8000` 직접 입력 |
| 자동발급 버튼이 없음 | 새로고침(F5) → 상단 "에이전트 연결됨" 표시 확인 |
| 발급이 멈춘 듯함 | 카드의 **진행 실화면**·안내 문구 확인(대부분 휴대폰 인증 대기) — [⏹ 중단] 후 재시도 가능 |
| 그 외 오류 | 🤖 [발급 전 점검] → [진단 복사] 결과를 저장소 이슈로 보내주시면 바로 확인합니다 |

## 5. 소스 실행 (경로 C · 검증용)

```bash
# 웹(전 기능 — 자동발급 제외): 정적 빌드
cd frontend && npm ci && npm run build && npm run preview

# 데스크탑 동일 셋업(자동발급 포함): 
cd frontend && npm run build:app
cd ../backend && python -m venv venv && venv/bin/pip install -r requirements-local.txt  # 또는 requirements.txt
RPA_ENABLED=1 venv/bin/python -m uvicorn local_server:app --host 127.0.0.1 --port 8000
# → http://localhost:8000/
```

품질 게이트(제출 시점 전부 통과): 자동테스트 **1,037**(vitest 775 + pytest 262) · 실브라우저 E2E 12스위트
(데스크탑 30종 포함) · 접근성 axe 위반 0 · ESLint/TypeScript 0 — 재현: `check-all.bat` 또는 저장소 README §품질.
