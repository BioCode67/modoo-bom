# 모두봄(ModooBom) 실행 가이드

> 2026 AI·SW중심대학 디지털 경진대회 SW부문 · 본선 산출물 [필수 2) 직접 실행 가능한 데모]의 실행 가이드입니다.
> 개인 복지 자산 관리 AI Agent로, 복지 추천부터 정부24 서류 자동발급, 복지로 자동신청까지 다룹니다.

---

## 0. 한눈 요약 — 실행 경로는 세 가지입니다

| 경로 | 준비물 | 시간 | 볼 수 있는 것 |
|---|---|---|---|
| A. 웹 (설치 없음) | 브라우저만 | 0분 | 추천, AI 의미검색, 통화 상담, 계산기 등 전 기능(자동발급 제외) |
| B. 데스크탑 앱 (권장) | Windows 10/11 | 2분 | A 전부 + 서류 자동발급·자동신청·서류함 (앱의 핵심) |
| C. 소스 실행 (개발자용) | Python 3.11+, Node 20+ | 5분 | B와 동일 |

- A. 웹: https://biocode67.github.io/modoo-bom/ 에서 지금 바로 열립니다.
- B. 데스크탑 앱: 제출 폴더의 `ModooBom-Setup.exe` 를 더블클릭(설치형)하거나, `ModooBom-Agent.zip` 을 압축 해제한 뒤
  `모두봄-에이전트.exe` 를 더블클릭(무설치)합니다. 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
  [추가 정보] → [실행]을 눌러 주세요. 코드서명 인증서(유료)를 붙이지 않은 오픈소스 데모라서 표시되는 정상 안내입니다.
- C. 소스: 저장소 루트에서 `setup-local.bat`(최초 1회)을 실행한 뒤 `run-local-app.bat` 을 실행합니다. (macOS/Linux는 아래 5번을 참고해 주세요.)

앱을 실행하면 검은 콘솔 창(에이전트이며, 닫으면 종료됩니다)이 뜨고 브라우저가 `http://localhost:8000/` 을 자동으로 엽니다.

## 1. 3분 핵심 코스 (데스크탑 앱)

1. 홈의 "말 한마디로 복지 찾기"에 상황을 입력하거나 음성으로 말합니다. 예를 들어 `72세 혼자 사는데 소득이 적어요`
   라고 입력하면 곧바로 분석과 결과 화면(현금성 혜택 합계, TOP3, 신뢰 근거)이 나옵니다.
2. 결과의 새싹이 카드에서 [오토파일럿] 버튼 하나로 추천을 전부 담고, 나의 복지로 자동 이동한 뒤 서류 연쇄 발급까지
   이어서 진행합니다(인증정보가 비어 있으면 입력칸으로 안내합니다). 수동으로 하시려면 [담기]를 누른 뒤 나의 복지 탭의
   서류 준비 도우미가 필요한 서류를 자동으로 정리해 드립니다.
3. 상태 표시줄의 [발급 전 점검]은 브라우저, 정부24·복지로 연결, 발급 폴더, 디스크, 서류함 무결성 여섯 항목을 실제로
   점검해 보여줍니다(실패도 숨기지 않는 정직한 설계입니다).
4. [자동] 버튼으로 서류를 자동 발급합니다. 실명·생년월일·휴대폰을 입력하고 시작하면 시스템 Chrome 또는 Edge가 열리고
   정부24 로그인부터 양식 입력까지 자동으로 진행됩니다. 카카오/PASS 간편인증만 직접 휴대폰에서 승인하면 PDF가
   발급되어 서류함에 저장됩니다(진행 화면이 카드에 실시간으로 표시됩니다).
5. 원클릭 연쇄: 정책 상세의 에이전트 신청은 필요 서류를 로그인 인증 한 번으로 연쇄 발급하고, 방금 발급한 서류를
   복지로 신청 양식에 자동 첨부한 뒤 정보를 자동 입력하고 제출 직전에 멈춥니다. 최종 제출 버튼은 자동으로 누르지
   않으므로, 실제 신청이 접수될 걱정 없이 살펴보실 수 있습니다.

## 2. 본인인증 없이 확인할 수 있는 것 (휴대폰 인증을 원치 않으실 때)

자동발급의 본인인증은 법적 요구사항이라 사람이 직접 승인해야 하지만, 아래 항목은 인증 없이 그대로 확인됩니다.

- [발급 전 점검](여섯 항목 실점검)과 [진단 복사](개인정보를 담지 않는 기술 진단)
- 자동발급 시작부터 정부24 로그인 화면까지의 자동 진행과 진행 화면(인증 대기 상태에서 [중단]할 수 있습니다)
- 내 서류함: 카메라로 서류를 찍어 자동 보정과 민감정보 가리기를 거쳐 제출용 PDF로 등록하고, 손상 여부를 관리하며,
  묶음 ZIP으로 내려받습니다
- 커버리지 실측 확장: 서류 이름 하나로 정부24를 실제로 조사해 자동발급 목록을 그 자리에서 늘리는 기능입니다(후보
  열한 종을 한 번에 실측하며, 자동신청도 정책 상세에서 동일하게 됩니다). 조사에는 로그인이나 개인정보가 쓰이지 않습니다.
- 통화형 상담(말로 묻고 소리로 답), 온디바이스 다국어 AI 의미검색(한국어·영어·베트남어·중국어), 급여 계산기,
  긴급복지 진단, 생애주기 시뮬레이터. 웹(A 경로)에서도 동일하게 동작합니다.

## 3. 요구 환경과 유의사항

- Windows 10/11과 Chrome 또는 Edge가 필요합니다(윈도우에 선탑재되어 있어 별도 설치가 필요 없습니다). 관리자 권한도
  필요 없습니다.
  - 기본 브라우저가 Chrome이 아니어도 됩니다. 자동발급은 앱이 Chrome, Edge 순으로 직접 구동하며(둘 다 없을 때만
    실패를 안내합니다), 앱 화면도 크롬이나 엣지를 우선 엽니다(없으면 기본 브라우저로 폴백합니다).
- 인터넷 연결이 필요합니다(정부24·복지로 실사이트를 자동화합니다). 사내망 등에서 정부 사이트가 차단되면 [발급 전
  점검]이 원인을 그대로 보여줍니다.
- 포트 8000이 사용 중이면 해당 프로그램을 종료한 뒤 다시 실행해 주세요.
- 개인정보: 이름·생년월일·연락처는 자동입력을 위해 이 PC 안에서만 쓰이며 외부 서버로 전송되지 않습니다. 발급 문서는
  `바탕화면\모두봄서류` 폴더에만 저장되고, 앱의 [새 상담 시작]으로 한 번에 삭제할 수 있습니다.
- LLM API 키 없이도 전 기능이 동작합니다(클라이언트 규칙 엔진과 Mock 모드로 설계했습니다).

## 4. 문제 해결

| 증상 | 조치 |
|---|---|
| 파란 "PC 보호" 창 | [추가 정보] → [실행] (미서명 오픈소스 데모의 정상 안내) |
| 브라우저가 안 열림 | 브라우저에서 `http://localhost:8000` 을 직접 입력 |
| 자동발급 버튼이 없음 | 새로고침(F5) 뒤 상단의 "에이전트 연결됨" 표시 확인 |
| 발급이 멈춘 듯함 | 카드의 진행 화면과 안내 문구 확인(대부분 휴대폰 인증 대기입니다), [중단] 뒤 재시도 가능 |
| 그 외 오류 | [발급 전 점검] → [진단 복사] 결과를 저장소 이슈로 보내주시면 확인하겠습니다 |

## 5. 소스 실행 (경로 C · 검증용)

```bash
# 웹(전 기능 — 자동발급 제외): 정적 빌드
cd frontend && npm ci && npm run build && npm run preview

# 데스크탑 동일 셋업(자동발급 포함):
cd frontend && npm run build:app
cd ../backend && python -m venv venv && venv/bin/pip install -r requirements-local.txt  # 또는 requirements.txt
RPA_ENABLED=1 venv/bin/python -m uvicorn local_server:app --host 127.0.0.1 --port 8000
# → http://localhost:8000/
```

품질 게이트(제출 시점 전부 통과): 자동테스트 1,643건(프론트 vitest 1,308, 백엔드 pytest 335), 실브라우저 E2E 12스위트(데스크탑
30종 포함), 접근성 axe 위반 0, ESLint/TypeScript 0. 재현은 `check-all.bat` 또는 저장소 README의 품질 항목을
참고해 주세요.
