# 모두봄(ModooBom) — 심사위원 실행 가이드

> 2026 AI·SW중심대학 디지털 경진대회 SW부문 · 본선 산출물 [필수 2) 직접 실행 가능한 데모]의 실행 가이드입니다.
> 개인 복지 자산 관리 AI Agent로, 복지 추천부터 정부24 서류 자동발급과 복지로 자동신청까지 지원합니다.

---

## 0. 실행 경로 요약

실행 방법은 세 가지이며, 심사 목적에 따라 선택하시면 됩니다.

| 경로 | 준비물 | 소요 | 확인 가능한 범위 |
|---|---|---|---|
| A. 웹 (설치 없음) | 브라우저 | 즉시 | 추천·AI 의미검색·통화 상담·계산기 등 자동발급을 제외한 전 기능 |
| B. 데스크탑 앱 (권장) | Windows 10/11 | 약 2분 | A의 전 기능 + 서류 자동발급·자동신청·서류함 |
| C. 소스 실행 (개발자용) | Python 3.11+, Node 20+ | 약 5분 | B와 동일 |

- A. 웹: https://biocode67.github.io/modoo-bom/ 에서 바로 실행됩니다.
- B. 데스크탑 앱: 웹 사이트(위 A) 홈 화면에서 'Windows 앱 바로 받기' 버튼을 누르면 설치 파일이 바로 내려받아집니다.
  (Windows로 접속하시면 버튼이 표시됩니다.) 처음 실행 시 "Windows의 PC 보호" 창이 나타나면
  [추가 정보] → [실행]을 눌러 주십시오. 코드서명 인증서를 적용하지 않은 오픈소스 데모에서 표시되는 정상 안내입니다.
- C. 소스: 저장소 루트에서 `setup-local.bat`(최초 1회)을 실행한 뒤 `run-local-app.bat`을 실행합니다.
  (macOS/Linux는 5절 참고)

앱을 실행하면 에이전트 콘솔 창이 뜨고(창을 닫으면 종료됩니다), 브라우저가 `http://localhost:8000/`을 자동으로 엽니다.

## 1. 핵심 심사 코스 (데스크탑 앱, 약 3분)

1. 홈 화면의 "말 한마디로 복지 찾기"에 상황을 입력하거나 음성으로 말합니다.
   예: `72세 혼자 사는데 소득이 적어요` → 분석 결과 화면(현금성 혜택 합계, 상위 3건, 판정 근거)이 표시됩니다.
2. 결과 카드의 [오토파일럿] 버튼을 누르면 추천을 모두 담고 '나의 복지'로 이동한 뒤 서류 연쇄 발급까지
   이어집니다(인증정보가 비어 있으면 입력란으로 안내). 수동으로 진행하려면 [담기] → '나의 복지' 탭 →
   '서류 준비 도우미'가 필요한 서류를 정리해 줍니다.
3. 상태 표시줄의 [발급 전 점검]은 브라우저 기동, 정부24·복지로 연결, 발급 폴더, 디스크, 서류함 무결성 등
   6개 항목을 실제로 점검해 보여 줍니다(실패 항목도 그대로 표시합니다).
4. [자동] 버튼으로 서류를 발급합니다. 이름·생년월일·휴대폰을 입력하고 시작하면 시스템에 설치된 Chrome 또는 Edge가
   열리고 정부24 로그인과 양식 입력이 자동으로 진행됩니다. 카카오·PASS 간편인증만 심사위원 휴대폰에서 승인하면
   PDF가 발급되어 서류함에 저장됩니다(진행 화면이 카드에 실시간 표시됩니다).
5. 정책 상세의 에이전트 신청(원클릭 연쇄)은 필요한 서류를 로그인 1회로 연쇄 발급하고, 방금 발급한 파일을
   복지로 신청 양식에 자동 첨부한 뒤 정보를 채워 제출 직전에 멈춥니다.
   최종 제출 버튼은 자동으로 누르지 않으므로, 실제 신청이 접수될 우려 없이 확인하실 수 있습니다.

## 2. 본인인증 없이 확인 가능한 범위

자동발급의 본인인증은 법적으로 사람이 승인해야 하는 절차입니다. 인증을 원치 않으시면 아래 항목만으로도
동작을 확인하실 수 있습니다.

- [발급 전 점검](6개 항목 실점검), [진단 복사](개인정보를 포함하지 않는 기술 진단)
- 자동발급 시작부터 정부24 로그인 화면까지의 자동 진행 및 진행 화면(인증 대기 상태에서 [중단] 가능)
- 내 서류함: 서류 촬영 → 자동 보정·민감정보 마스킹 → 제출용 PDF 등록, 무결성(손상 여부) 관리, 묶음 ZIP
- 커버리지 실측 확장: 서류 이름 하나로 정부24를 실제 조사해 자동발급 목록을 즉시 늘리는 기능
  (후보 11종 일괄 실측, 자동신청도 정책 상세에서 동일). 조사 과정에는 로그인·개인정보를 사용하지 않습니다.
- 통화형 상담(말로 묻고 음성으로 답변), 온디바이스 다국어 AI 의미검색(한국어·영어·베트남어·중국어 등),
  급여 계산기, 긴급복지 진단, 생애주기 시뮬레이터 (웹 경로에서도 동일)

## 3. 실행 환경 및 유의사항

- Windows 10/11과 Chrome 또는 Edge(윈도우 기본 탑재)가 필요하며, 별도 설치나 관리자 권한은 필요하지 않습니다.
- 정부24·복지로 실사이트를 자동화하므로 인터넷 연결이 필요합니다. 사내망 등에서 정부 사이트가 차단된 경우
  [발급 전 점검]이 원인을 표시합니다.
- 포트 8000이 사용 중이면 해당 프로그램을 종료한 뒤 다시 실행해 주십시오.
- 이름·생년월일·연락처는 자동입력을 위해 심사위원 PC 안에서만 사용되며 외부 서버로 전송되지 않습니다.
  발급 문서는 `바탕화면\모두봄서류` 폴더에만 저장되며, 앱의 [새 상담 시작]으로 일괄 삭제할 수 있습니다.
- LLM API 키가 없어도 전 기능이 동작합니다(클라이언트 규칙 엔진과 Mock 모드로 구성).

## 4. 문제 해결

| 증상 | 조치 |
|---|---|
| 파란 "PC 보호" 창 | [추가 정보] → [실행] (미서명 오픈소스 데모의 정상 안내) |
| 브라우저가 열리지 않음 | 브라우저에 `http://localhost:8000`을 직접 입력 |
| 자동발급 버튼이 보이지 않음 | 새로고침(F5) 후 상단의 "에이전트 연결됨" 표시 확인 |
| 발급이 멈춘 것처럼 보임 | 카드의 진행 화면·안내 문구 확인(대개 휴대폰 인증 대기). [중단] 후 재시도 가능 |
| 그 밖의 오류 | [발급 전 점검] → [진단 복사] 결과를 저장소 이슈로 전달 |

## 5. 소스 실행 (경로 C · 검증용)

```bash
# 웹 (자동발급 제외 전 기능): 정적 빌드
cd frontend && npm ci && npm run build && npm run preview

# 데스크탑 동일 구성 (자동발급 포함):
cd frontend && npm run build:app
cd ../backend && python -m venv venv && venv/bin/pip install -r requirements-local.txt  # 또는 requirements.txt
RPA_ENABLED=1 venv/bin/python -m uvicorn local_server:app --host 127.0.0.1 --port 8000
# http://localhost:8000/
```

제출 시점 기준 품질 게이트는 모두 통과 상태입니다. 자동테스트 1,581건(프론트 vitest 1,273, 백엔드 pytest 308),
실브라우저 E2E 12스위트(데스크탑 30종 포함), 접근성 검사(axe) 위반 0, ESLint·TypeScript 오류 0이며,
`check-all.bat` 또는 README의 품질 항목으로 재현할 수 있습니다.
