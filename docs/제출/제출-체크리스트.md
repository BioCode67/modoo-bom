## 데모 제출 방식 (2026-07-20 결정)

데모는 **웹 링크를 기본**으로 제출하고, **데스크탑 앱은 별도 zip 없이 사이트/릴리스에서 내려받도록 안내**합니다.

- 근거: `releases/latest` 링크는 재배포 시 자동으로 최신본을 가리키므로, 제출 후 버그를 수정해도 반영됩니다(zip은 그 시점에 고정).
- 데이콘 요건상 "웹으로 구동되는 경우 웹 링크 제출"에 해당하므로 `모두봄_데모파일.zip`은 제출하지 않습니다.
- 데스크탑 앱 다운로드: 사이트 홈의 'Windows 앱 받기' 버튼 또는 https://github.com/BioCode67/modoo-bom/releases/latest

```
├── 모두봄_GitHub링크.txt      ← docs/제출/드라이브-업로드/모두봄_GitHub링크.txt  (업로드 완료)
├── 모두봄_데모링크.txt         ← docs/제출/드라이브-업로드/모두봄_데모링크.txt  (웹 + 데스크탑 다운로드 링크)
├── 모두봄_실행가이드.pdf       ← docs/제출/심사위원-실행-가이드.pdf (이름만 변경)
├── 모두봄_발표자료.pdf         ← docs/발표/본선-발표자료-초안.pdf (16장·약 10분 · 이름만 변경)
└── 모두봄_시연영상.mp4 (선택)  ← [사람] 녹화
```
