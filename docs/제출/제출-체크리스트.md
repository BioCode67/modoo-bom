## §빌드 — 데스크탑 exe v0.3.2 (Windows PC에서, 약 10분)

```
1) git pull                      ← main 최신(오늘 배포 #157까지)
2) setup-local.bat               ← 최초 1회(venv-local + 프론트 빌드 준비)
3) build-installer.bat           ← dist-app → PyInstaller → ZIP → (Inno Setup 있으면) Setup.exe
4) backend\dist\ 의 모두봄-설치.exe / 모두봄-에이전트.zip 을 드라이브 02_데모/에 업로드
5) 업로드 전 1회 실행 확인: 설치 → 실행 → [발급 전 점검] 6항목 → 서류 1종 실발급 완주
```

> 신뢰 근거: 이 컨테이너에서 **같은 spec으로 PyInstaller 번들을 실제 빌드·기동**해
> v0.3.2 신기능(실측 프로브·프리플라이트 6항목 등) 모듈 포함을 전부 확인했습니다(2026-07-19).
> Windows 빌드에서 남는 변수는 Inno Setup 유무뿐(없으면 ZIP만 제출해도 무설치 실행 가능 — 가이드에 안내됨).
