## 제출 파일 (이 폴더)

| 파일 | 용도 | 사양 |
|------|------|------|
| `모두봄_포스터.pptx` | 제출 ① PPT 1장 | 슬라이드 1장 · 70×140cm · 공식 양식 캔버스 |
| `모두봄_포스터.pdf` | 제출 ② PDF 변환본 | 1페이지 · 70×140cm · 벡터 텍스트 |

두 파일은 **같은 원본(`poster.html`)에서 생성**되어 화면이 완전히 동일합니다.
PDF는 벡터 텍스트라 인쇄 품질이 가장 좋고, PPTX는 같은 화면을 200DPI 이미지로 담아
**심사자 PC에 폰트가 없어도 레이아웃이 깨지지 않습니다.** 양식 1페이지(제출 안내)는 규정대로 삭제했습니다.

## 다시 만들기

```bash
cd docs/제출/포스터
python render.py       # poster.html → 모두봄_포스터.pdf (Chromium 인쇄, 70×140cm)
python build-pptx.py   # PDF → 200DPI 래스터 → 공식 양식 1장에 전면 배치
```

`build-pptx.py`는 협의회 배포 **공식 양식(`template.pptx`)이 같은 폴더에 있어야** 동작합니다.
양식은 배포처 자료라 저장소에 포함하지 않았습니다 — 공지의 양식 다운로드 링크에서 받아 두세요.

## 내용 수정

`poster.html` 한 곳만 고치면 두 파일에 함께 반영됩니다(위 두 명령 재실행).
자산은 `assets/`에 있습니다 — 공식 배경(`bg.jpg`), 데모 QR(`qr.png`), 현장 사진, 폰트,
실제 화면 캡처(`assets/shots/`).

- 화면 캡처를 갱신하려면 배포본을 띄운 상태에서 새로 찍어 `assets/shots/`를 교체하세요.
- 수치(테스트 건수·정책 건수)는 저장소 문서와 같은 값을 씁니다 — 바뀌면 함께 갱신.
