# 데이터 확장 — 어떤 API가 필요한가 (정리)

> 사용자 요청("api 필요하면 정리해서 말해줘")에 대한 정리. **키 발급이 필요한 것**과
> **키 없이 가능한 것**을 나눠 적는다. 현재 데이터: 시드 큐레이션 190 + 공공데이터 5,143 ≈ **약 5,300건**.

|---|---|---|---|

## 추가하면 좋은 API (우선순위)

### ⭐ 1순위 — 온통청년 청년정책 OpenAPI (가장 큰 효과)
- **무엇**: 국무조정실 온통청년(youthcenter.go.kr)의 **전국 청년정책 통합 DB**. 중앙+지자체 청년정책 수천 건.
- **왜**: 우리 앱의 청년 사용자 비중이 크고, 청년정책은 갱신이 빨라 큐레이션만으론 한계. 이 API가 그 공백을 메움.
- **키**: data.go.kr 또는 온통청년 오픈API 신청(무료). 엔드포인트: 청년정책 목록/상세.
- **작업량**: `etl/ingest_welfare.py`에 청년정책 파서 1개 추가(기존 정규화 로직 재사용). id 접두사 `YTH-` 제안.
- **주의**: 필드 매핑(지원내용→benefit, 지원대상→target/eligibility) + 마감일(`deadline.ts`와 연동 가능).

### 2순위 — 중앙부처 복지서비스 상세 (서비스 15090532)
- data.go.kr, **활용신청 후 승인 필요**(즉시 아님). 승인되면 중앙부처 복지서비스 **상세 필드**(구비서류·문의처 등) 보강.
- 현재 요약형(GOV-)의 저신뢰 매칭을 정밀 매칭으로 끌어올릴 수 있음.

### 3순위 — 지자체별 공공데이터(선택)
- 서울 열린데이터광장, 경기데이터드림 등 광역 포털에 청년·주거·출산 관련 개별 데이터셋 다수.
- 표준화가 제각각이라 **투자 대비 효과는 중간**. 필요한 지역만 선별 권장.

## 굳이 API가 필요 없는 것 (큐레이션이 정답)

K-패스·신생아 특례대출·재난적 의료비·행복주택·두루누리 등 **핵심 대형 사업**은 공개 OpenAPI가 없거나
불안정하다. 이건 **직접 큐레이션**(공식 사이트 실측 검증 + 라이브 공고 게시판 딥링크)이 더 정확하고 정직하다.
→ 이번에 `govPrograms.ts`(정부 지원사업)·`housingPolicies.ts`(청년주택 공고)로 이 방식 확장 중.

---

## 정리: 사용자가 해줄 것

- **키 1개만 더 받으면 큰 효과**: data.go.kr에서 **온통청년/청년정책** 관련 오픈API 활용신청(무료, 즉시~1일).
  받은 키를 `backend/.env`에 추가로 넣어주면 ETL로 청년정책 수천 건을 자동 병합 가능.
- 나머지(핵심 대형 사업)는 코드 큐레이션으로 계속 채운다 — **키 불필요**.
