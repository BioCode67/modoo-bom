복지로 딥링크(wlfareInfoId)를 라이브 실측 검증한 6종. 데스크탑 앱에서 [신청하기] → 복지로 로그인(간편인증) →
신청 양식 자동작성 → 발급 서류 자동첨부 → **제출 버튼만 본인이**.

단, 복지로 페이지에 '신청하기' 버튼이 없는 서비스(방문·우편 전용)는 정보 페이지 안내로 폴백 —
버튼 존재 여부는 서비스별이라 6종 외에는 "시도 후 폴백" 모델.

### ③ 무설치 원터치 핸드오프 (전체) — 설치 없이 웹에서
딥링크가 없거나 앱 미설치 사용자는: [신청] 클릭 → 내 정보 클립보드 복사 + 공식 신청 페이지 새 탭 →
정부 사이트에서 인증만. 어떤 기기·브라우저든 동작(현재 배포 웹 기본 경로).

## 온라인 신청이 안 되는 것들 (정직 안내)
- 주민센터 방문 전용 복지(상당수 지자체 사업) → 앱의 '주민센터 방문 키트'(큰 글씨 A4 인쇄)로 지원
- 심사·선발형 민간재단(장학 등) → 각 재단 사이트 안내
- 최종 '제출'과 본인인증은 법적으로 본인 몫 — 어떤 단계에서도 대신 누르지 않음

## 자동발급 지원 서류 (15종) — "일일이 로그인해서 하나하나" 해결
정부24 13종: 주민등록등본·초본 / 가족관계증명서 / 장애인증명서 / 소득금액증명 /
지방세 납세증명서·세목별 과세증명서 / 기초생활수급자 증명서 / 한부모가족 증명서 /
**국세 납세증명서 / 출입국에 관한 사실증명 / 병적증명서 / 건강보험료 납부확인서**(07-11 확장, AA020 실측)
+ 건강보험 자격득실확인서(건보공단) + 고용보험 피보험자격 이력내역서(고용24)

**핵심: '전부 자동발급' 버튼(연쇄발급)** — 서류 도우미에서 한 번 누르면 필요한 서류들을
**한 번의 로그인·한 번의 폰 인증으로 순서대로 전부 발급**한다(orchestrator journey).
사이트마다 로그인하고 하나씩 받는 고통이 이미 이걸로 해결돼 있다 — 현장에서 이 버튼을 기본으로 쓸 것.

복지 신청에 실제로 요구되는 서류의 대부분(소득·가구·수급자격 증명)이 15종 안에 있다.
보류 2종(조사 완료·실측 근거): 차상위계층 확인서(13520000098 — 자격 보유자 한정, 발급폼 미확인이라
headed 리허설 검증 후 추가) · 국민연금 가입자 가입증명(정부24는 '3일 처리 신청' 민원이라 즉시발급 불가 —
국민연금공단 전자민원이 정식 경로, 별도 모듈 필요).

## 조사 노트 (07-12) — '신청하기 버튼' 비로그인 감지 실험
복지로 WLF 페이지 3종(기초연금·아동수당·에너지바우처)을 비로그인 헤드리스로 프로브한 결과
**전부 '신청하기' 요소가 렌더**됨 — 방문 전용 서비스와의 변별이 안 되는 신호라, 이 방법으로
"온라인신청 가능" 태깅을 하면 오정보 위험. 확실한 음성 표본(방문 전용 확정 서비스)을 확보하기
전까지 데이터 태깅 보류. 현행(시도 후 폴백 모델 + 6종 검증 목록)이 정직한 상태.
