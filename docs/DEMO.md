# 모두봄(ModooBom) — 데모 & 상세기획서용 하이라이트

> 개인 복지 자산 관리 AI Agent · 2026 AI·SW중심대학 디지털 경진대회 SW부문
> 라이브: **https://biocode67.github.io/modoo-bom/**

---

## 한 줄 소개
나이·소득·상황(또는 **어떤 언어로든** 한 문장)만 알려주면, **AI Agent**가 전국 5,000여 복지에서 내게 맞는 혜택을 찾아
신청 방법·필요 서류를 안내하고, **실제 정부 사이트 RPA**로 서류 발급·신청까지 도와주는 풀스택 서비스.

## 핵심 차별점 (심사 포인트)

1. **🌍 온디바이스 다국어 AI 복지 상담 (헤드라인)**
   - 브라우저에서 **직접 실행되는 신경망 임베딩 모델**(multilingual-e5-small)로 전국 5,000여 복지를 *의미*로 매칭.
   - **다국어 교차검색**: 한국어·English·Tiếng Việt(베트남어)·中文·日本語 등 어떤 언어로 물어도 한국 복지를 찾아줌.
     - "I lost my job and need money" → 긴급복지지원·자활근로
     - "Tôi là người khuyết tật"(베트남어) → 장애인 복지
     - "노인인데 돈이 없어요" → 노인·기초 소득지원
   - **AI 답변(대화형)**: 검색 나열이 아니라, 입력 언어를 이해했음을 알리고 **대표 복지·예상 금액을 한 줄로 요약 답변**(환각 없이 실제 검색결과 기반). 🔊 **음성으로 읽어줌**.
   - **음성 대화 루프**: 마이크로 **자국어로 말하면**(한/영/베트남/중/일 선택) AI가 듣고 → 의미 이해 → **음성으로 답**.
   - **끊김 없는 UX**: 모델 로딩 중엔 즉시 키워드 결과를 보여주고, 준비되면 AI 의미검색으로 자동 업그레이드(빈 화면 없음). 입력 언어 자동감지 배지.
   - **어디서든**: 홈/복지찾기에 외국어를 입력하면 자동으로 AI 의미검색으로 라우팅.
   - **서버 전송 0**: 모델·추론 전부 사용자 기기 안에서 실행 → 프라이버시 보장(최초 1회 모델 다운로드 후 캐시).
   - **사회적 의미**: 언어 장벽으로 복지에서 소외된 **외국인·다문화 가정**(복지 사각지대)을 정면으로 겨냥.
     외국어 감지 시 다누리콜센터(13개 언어 상담) 자동 안내.

2. **🤖 실제 정부 사이트 RPA 자동화 (과장 없는 현실 자동화)**
   - 정부24(plus.gov.kr)·복지로·건강보험공단·고용24를 **실제 브라우저로 자동 조작**.
   - 로그인→간편인증→서류 발급/신청 폼 작성까지 자동. **카카오 본인인증·최종 제출만 본인**(비가역·법적 행위라 의도된 안전장치).
   - 배포된 웹이 사용자 PC의 **로컬 에이전트(localhost:8000)** 를 감지해 정적 사이트에서도 실제 자동화 활성화.

3. **🔒 프라이버시 우선 · 회원가입 없이**
   - 입력 정보는 서버가 아닌 **내 기기(localStorage)** 에만. AI도 기기 내 실행. 회원가입 불필요.

4. **📚 5,000여 건 실데이터**
   - 보건복지부 검증 시드 + 한국사회보장정보원 공공데이터(복지로) = 약 5,000건. 2026년 기준 금액·선정기준 검증.

## 데모 시나리오 (권장 순서)

1. **홈** — 3D 새싹 마스코트 히어로 + "다국어 AI 의미 검색 (NEW)" 카드 → **[지금 체험하기]** 클릭.
2. **AI 의미 검색** — 탐색 화면에 AI 모드 자동 ON. 다국어 예시 칩 클릭 또는 직접 입력:
   - 영어 "I lost my job and need help" → 긴급복지 등 매칭(🤖 AI 매칭 배지, 감지 언어 🇬🇧 표시).
   - 베트남어 "Tôi cần hỗ trợ tiền thuê nhà" → 주거/청년 지원 매칭.
3. **복지 찾기(분석)** — 프로필 위저드 또는 자연어 한 문장 → 맞춤 결과·예상 금액·필요 서류.
4. **나의 복지** — 관심 저장·신청 상태 관리·현금성 혜택 합산·사후관리 모니터링.
5. **(로컬 에이전트 실행 시) 서류 자동발급** — 정부24 등본 발급 RPA → Edge 창에서 카카오 인증 후 자동 발급·PDF 저장.

## 데모 팁 (중요)

- **AI 모델 프리워밍**: AI 의미 검색은 최초 1회 모델(~128MB)을 CDN에서 내려받습니다(수십 초). **시연 직전 AI 토글을 한 번 켜서 미리 로드**하면(브라우저 캐시) 판정 중엔 즉시 반응합니다. 이후 재방문도 즉시.
- **브라우저**: Chrome/Edge 권장(로컬 에이전트·정부 RPA는 실제 Edge 창 사용).
- **RPA 시연**: 프로젝트 루트 `run-windows.bat` 실행(백엔드:8000) 후, 라이브 사이트에서 서류 자동발급 클릭 → Edge 창에서 카카오 폰 인증.

## 기술 스택 요약
- **Frontend**: React 18 · Vite · TypeScript · Tailwind · React Three Fiber(3D) · framer-motion · **transformers.js(온디바이스 AI)** · zustand · PWA
- **Backend**: FastAPI · LangGraph(10노드 에이전트) · ChromaDB(RAG) · **Playwright RPA** · Anthropic Claude(또는 Mock 모드)

## 정직성 원칙 (과장하지 않음)
- 완전 무인 자동 제출은 **설계상 불가**(정부 본인인증 필수 + 비가역) — human-in-the-loop가 정답.
- 가짜 데이터·가짜 상태 미생성. 실제 검증된 것만 "된다"고 표기.
- 공공데이터 정책은 요약 정보라 실제 자격·금액과 다를 수 있어, 복지로/주민센터(☎129) 확인을 함께 안내.
