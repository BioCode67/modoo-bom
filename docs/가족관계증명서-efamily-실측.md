# 가족관계증명서 발급 경로 실측 (2026-07-20 새벽, 실사용 스크린샷 기반)

## 결론

- **원 발급처는 대법원 전자가족관계등록시스템(efamily.scourt.go.kr)** — 인터넷 발급 **무료·24시간**(새벽 4시 발급 실측 확인).
- **정부24는 안내 페이지일 뿐**: `gov.kr/mw/AA020InfoCappView.do?CappBizCD=97400000004`는 '사이트 가기' 버튼으로
  efamily로 보낸다. 정부24 자체 전자발급 경로는 **'전자문서지갑'(정부24 모바일 앱 설정) 선행 요구** + 연계 차단이 잦아
  야간에 "서비스 점검 중" 팝업이 뜨었다(앱이 이걸 감지해 정직 안내로 전환 — `_is_wallet_required`/`_maintenance_msg`).
- 앱의 가족관계 [전자발급] 링크는 efamily 직행으로 변경함(`officialLinks.ts`).

## efamily 발급 흐름 (스크린샷 실측)

1. `https://efamily.scourt.go.kr/index.jsp` → 증명서발급 그리드에서 **가족관계증명서** 클릭
2. **가족관계등록부 신청인 정보 조회** 페이지 (`/pt/PtFrrpApplrInfoInqW.do?menuFg=02`):
   - 이용약관 스크롤 박스 + **"위 이용약관에 동의합니다" 체크박스**
   - (선택) 키보드보안 프로그램 적용 체크박스
   - 필수 입력: **성명** / **주민등록번호**(앞 6자리 + **뒷 7자리**, 라디오로 재외국민 식별번호 대체 가능)
     / **추가정보확인**(드롭다운: 부 성명·모 성명 등 + 이름 입력)
   - 인증 버튼 3종: 공동인증서 · 금융인증서 · **간편인증**
3. **간편인증 모달**: 민간인증서 그리드(카카오톡·신한·IBK·네이버·카카오뱅크·토스·NH·PASS·삼성패스·뱅크샐러드·하나·우리·KB)
   + 본인인증 정보(이름·주민번호 앞자리는 이전 단계에서 승계, **뒷자리 재입력**·휴대폰) + 전체동의 + **인증 요청**
4. 폰 승인 → 이후 증명서 종류(일반/상세 등) 선택 → **신청하기** → 발급(출력/PDF)

## 완전 자동화를 보류한 이유 (정직성)

- efamily는 **주민등록번호 뒷 7자리 + 부/모 성명**을 요구한다. 모두봄은 프라이버시 설계상
  이름·생년월일·휴대폰만 수집하므로, 자동화하려면 **민감 PII 수집 확대**가 필요하다(신중 결정 사안).
- 정부24와 완전히 다른 사이트라 새 RPA 모듈이 필요하고, 컨테이너에서 실측 불가(정부망 차단) →
  검증 없는 코드를 본선 직전에 넣지 않는다(날조 금지 원칙).
- **현재의 정직한 UX**: 앱은 efamily 직행 링크로 안내 → 사용자가 직접 발급(1~2분) →
  발급 PDF를 **내 서류함 등록**(`POST /api/documents/register`) 또는 **📷 서류 촬영**으로 넣으면
  신청 자동첨부(`가족관계증명서_이름` 규칙)에 그대로 합류한다.

## 구현 현황 (2026-07-20 — 실PC 완주 검증됨 ✅)

`gov24_rpa._issue_family_cert_efamily` 로 **efamily 직행 전자동** 구현·실발급 완주 확인
(`RPA_FAMILY_EFAMILY=0` 밸브). 앱 폼(자동입력 추가정보)에 🔒 주민번호 뒷 7자리·부/모 성명을
마스킹(●) 입력칸으로 추가(둘 다 password 표시·디스크/탭기억 미보관 — vitest 계약 고정, 서버 미저장):

① 신청인 정보조회 직행 → 약관 동의 + 성명·주민번호 앞/뒷·부/모 성명(드롭다운 공백무시 매칭) 전부
   자동 → [간편인증] 자동 오픈
② 인증 모달(프레임 인지 — iframe이어도 입력): 제공자 선택·주민번호·휴대폰·전체동의·[인증 요청] 자동
③ 폰 [인증 허용](유일한 본인 단계) → **'인증 완료' 12초 간격 자동 클릭**(미완료 안내는 닫고 재시도)
④ 열람/발급 신청 6단계: 1~4 기본값 유지(주민번호 '전부 비공개' 🔒) + '화면 열람'·'국내 기관 제출'
   자동 선택 → [신청하기] → **원본 PDF 직다운로드**(뷰어 재인쇄 잘림 해소, %PDF- 검증) → 서류함 저장.
실패 시 각 단계 정직 안내 + 화면 유지(사람이 이어서). '등록기준지' 신호로만 성공 판정(폼 캡처 오인 방지).

## 향후 자동화 시 참고 (선택 과제)

- 1단계(무인증 구간)만 반자동 가능: efamily 진입 → 가족관계증명서 클릭 → 약관 동의 체크 → 성명·주민번호 앞 6자리
  (생년월일) 프리필까지. 뒷자리·부모성명·인증은 사용자 직접(HITL).
- 간편인증 모달의 제공자 그리드는 정부24 oacx와 유사 구조(카카오톡 타일 + 전체동의 + 인증 요청) —
  기존 `click_provider_in_anyid`/`_autofill_auth_form` 패턴 재사용 여지 있음. 반드시 실PC 실측 후 등재.
