# 모두봄 데스크탑 앱 (Windows) — v0.3.0

## 밤샘 개선 (2026-07-19 새벽, deploy #69~#80)

**서류를 '모아주는' 앱으로** — 발급물이 폴더에 쌓이기만 하던 것을 관리되는 서류함으로:
- 🗂 서류함 항목에 **발급 경과·유효 배지**(3개월 지남 ⚠️ 재발급 권장 · 유효 확인) — 관공서 통용
  '발급 3개월 이내' 기준, 기관별 상이 명시
- 📦 **묶음 받기(ZIP)** — 종류별 최신 1건씩 한 파일로(복지로 수동 첨부·이메일 제출용).
  여정 종결 배너에서도 바로
- 🧾 **부족분만 자동발급** — 서류함에 유효한 실파일이 있으면 그건 건너뛰고 부족한 것만
  (건너뛴 이유 표시). 필요한 자동발급 서류가 전부 있으면 **[📨 자동신청만 진행]**
- 정책 상세 에이전트 신청에 **부족 서류 진단**("n종이 아직 없어요") + **[📦 이 신청에 쓸 서류만 ZIP]**
  (그 정책 서류가 실제 서류함에 있을 때만 노출 — 404 막다른 경로 없음)
- **표기 정규화** — '자녀 주민등록등본'·'한부모 확인서' 같은 변형도 정식 발급명으로 인식·발급
  (변형명이 백엔드에서 거절되던 잠재 결함 해소, 같은 문서 카드 자동 병합), '수급자 확인서'류엔
  💡대체 발급물 힌트
- 확장 도구: 정부24 CappBizCD·복지로 wlfareInfoId **실측 발굴 스크립트**(등재는 실발급/육안
  확인 후만 — 날조 금지 절차 문서화)
- 품질: 서류 카드 **큰글씨에서도 안 깨지게**(제목 줄바꿈 허용) · 접근성 자동감사(axe) 위반 0 ·
  '대출' 검색에서 서민금융이 잘리던 회귀 수정 · 앱 하단에 **버전·빌드날짜 표기**(캐시 진단 1초)

검증: 백엔드 pytest 193(컨테이너 가용분) · 프론트 vitest 728 · desktop-smoke 16종 · 웹 스모크 전 구간


내 복지, AI가 찾아주고 **서류 자동발급·신청까지** 도와주는 앱이에요.

## 📥 설치 (3단계)

**1) 내려받기**
- **`ModooBom-Setup.exe`** 를 클릭해 다운로드하세요. (설치형 · 권장)
- 설치가 부담되면 → `ModooBom-Agent.zip` 을 받아 압축을 풀고 안의 `모두봄-에이전트.exe` 를 더블클릭해도 됩니다.

**2) 실행 → "Windows의 PC 보호" 창이 뜨면 (정상이에요!)**
- 처음 실행하는 앱이라 파란 경고창이 떠요. 나쁜 게 아니라, 아직 서명(유료 인증서)을 안 붙여서예요.
- 창에서 **[추가 정보]** 를 누르면 → 아래에 **[실행]** 버튼이 나와요. **[실행]** 을 누르세요.
  > (오픈소스 데모 앱이고, 개인정보는 서버로 안 보내고 내 컴퓨터에서만 처리해요.)

**3) 설치 완료 → "지금 모두봄 실행" 체크 → 끝!**
- 시작메뉴·바탕화면에 **"모두봄"** 아이콘이 생겨요. 다음엔 그 아이콘만 누르면 됩니다.

---

## ▶ 실행하면 이렇게 돼요
1. **검은 창**이 하나 뜨고(모두봄이 여기서 돌아가요 — **닫지 마세요!**),
2. **브라우저가 자동으로 열려요.** (안 열리면 브라우저에 `http://localhost:8000` 입력)
3. 새싹이(AI)랑 대화 → 복지 추천 → **[자동] 버튼**으로 서류 발급 → **폰에서 카카오 '인증 허용'만** 누르면 발급 완료!
4. 다 쓰면 **검은 창을 닫으면** 종료돼요.

## ✅ 무엇이 되나요
- AI 에이전트와 대화로 내가 받을 수 있는 복지 추천 (설치 없이 웹에서도 됨)
- **서류 자동발급**: 정부24·건보공단 자동 접속 → 정보 자동입력 → 폰 인증만 (등본·초본·가족관계·소득·지방세·수급자·한부모·국세납세·출입국·병적·건보료납부·건보자격·고용 등 15종)
- **복지 신청**: 복지로 신청 화면까지 자동 이동·정보 자동작성 (본인인증·최종 제출은 본인)
- **🚀 원클릭 연쇄**: '전부 자동발급 + 자동신청까지' 한 번으로 — 서류 순차 발급 → 방금 발급물을
  신청 양식에 자동첨부 → 제출 직전 정지. 진행률 바 · [⏭ 이 단계 건너뛰기] · 종결 요약 제공

## 🆕 최신 코드로 실행하면 이런 것도 있어요 (`run-local-app.bat` — git 최신이면 자동 반영)
- 🗂 **내 서류함**(발급/등록물 목록·자동첨부 후보 배지·삭제) + 📷 **서류 촬영→제출용 PDF**
- 🤖 상태 스트립: **[발급 전 점검]**(브라우저·정부24/복지로 연결·폴더·디스크 5항목) · **[진단 복사]**(개인정보 없음)
- 📱 **인증 알림음**(+옵트인 **음성 안내** "휴대폰에서 인증 요청을 승인해 주세요") — 화면 안 봐도 폰 집을 타이밍
- 🔁 **이어보기**: 발급/신청 중 새로고침·화면 이동해도 돌아오면 자동 재연결
- ✅ 발급 성공은 자동으로 '발급 완료' 기억(재실행 시 중복 발급 안 함) · 신청 카드 '제출 완료 기록' 버튼

## 🔒 안전·프라이버시
- 이름·생년월일·연락처는 **내 컴퓨터에서만** 처리(서버 전송 없음), 본인인증은 정부 공식 절차
- 발급 문서는 **내 바탕화면 → 모두봄서류** 폴더에 저장돼요
