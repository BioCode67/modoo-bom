# 모두봄 데스크탑 앱 (Windows) — v0.3.0

내 복지, AI가 찾아주고 **서류 자동발급 · 신청까지** 도와주는 로컬 앱입니다.

## 받기 · 실행
- **`ModooBom-Setup.exe`** 더블클릭 → 설치 → 시작메뉴/바탕화면 "모두봄" 아이콘 실행
- 또는 **`ModooBom-Agent.zip`** 압축 해제 후 `모두봄-에이전트.exe` 더블클릭(설치 불필요)
- 실행하면 로컬 에이전트가 뜨고(약 1초) 브라우저가 `http://localhost:8000/` 을 자동으로 엽니다.

> ⚠️ 미서명 앱이라 처음 실행 시 Windows SmartScreen "Windows의 PC 보호" 경고가 뜰 수 있어요.
> **[추가 정보] → [실행]** 을 누르면 됩니다. (오픈소스 데모 앱, 개인정보는 기기에서만 처리)

## 무엇이 되나요
- **AI 에이전트 "새싹이"** 와 한 문장 대화로 내가 받을 수 있는 복지 추천
- **서류 자동발급**: 정부24·건강보험공단 등에 자동 접속 → 본인정보 자동입력 → '인증 요청'까지 →
  **폰에서 카카오 '인증 허용'만** 누르면 발급 (11종: 등본·초본·가족관계·소득금액·지방세·수급자·한부모 등)
- **복지 신청 자동화**: 복지로 신청 페이지까지 자동 이동·작성(본인인증·최종 제출은 본인 확인)

## 안전·프라이버시
- 개인정보(이름·생년월일·연락처)는 **기기 안에서만** 처리(서버 전송 없음), 본인인증은 정부 공식 절차
- 발급 문서는 **내 바탕화면/모두봄서류** 에 저장

## 필요 환경
- Windows 10/11 · Chrome 또는 Edge(선탑재) — 둘 다 없는 환경에서만 자동발급이 제한됩니다.
