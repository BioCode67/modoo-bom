- **📞 새싹이와 통화하기**: 챗 헤더 📞·복지 찾기 CTA — 전화 걸듯 말로 묻고 소리로 듣는 상담.

- 🔑 **진짜 '한 번 인증' 연쇄발급** — 정부24 서류가 2종 이상인 여정은 이제 **한 브라우저·한 로그인
  세션을 공유**해요. 전에는 서류마다 카카오 로그인 인증(3서류=승인 3회)이었지만, 이제 **로그인 인증은
  1회**이고 이후 서류는 "같은 로그인으로 이어서" 폼에 직행해요. (서류별 전자서명 인증은 정부24 정책에
  따라 필요한 경우 그대로 — 없는 걸 없앤 척하지 않아요. 로그인 만료·창 닫힘은 자동 복구.)
- 🔁 **오류 서류 자동 재시도** — 서류 하나가 일시 오류로 실패하면 여정을 끊지 않고 **같은 로그인으로
  1회 자동 재시도**해요(두 번째도 실패하면 정직하게 오류로 표시하고 다음 서류로).

- 🗂 **서류 골라 일괄발급** — 담은 정책과 무관하게 지원 15종에서 체크해 **한 번 인증으로 연쇄 발급**
  (부족분 기본 선택 · 서류함 보유분 `🗂 있음` 표시 · 중복 발급 가드)
- 📷 촬영 업그레이드 — ✂️ 자르기에 **문서 영역 자동 감지**(밝기 기반 제안) + **🖍 민감정보 가리기**
  (주민번호 뒷자리를 드래그로 덮어 **픽셀째 저장** — 파일에 원본이 안 남음). 전부 기기 안 처리.
- 🗂 서류함 **종류별 그룹핑** — 재발급이 쌓여도 최신본 1줄 + 이전 버전 접기(묶음 ZIP·자동첨부와 동일 기준)

## 밤샘 개선 (2026-07-19 새벽, deploy #69~#85)

**서류를 '모아주는' 앱으로** — 발급물이 폴더에 쌓이기만 하던 것을 관리되는 서류함으로:
- 🗂 서류함 항목에 **발급 경과·유효 배지**(3개월 지남 ⚠️ 재발급 권장 · 유효 확인) — 관공서 통용
  '발급 3개월 이내' 기준, 기관별 상이 명시
- 📦 **묶음 받기(ZIP)** — 종류별 최신 1건씩 한 파일로(복지로 수동 첨부·이메일 제출용).

  (건너뛴 이유 표시). 필요한 자동발급 서류가 전부 있으면 **[📨 자동신청만 진행]**

## 📥 설치 (3단계)

**1) 내려받기**
- **`ModooBom-Setup.exe`** 를 클릭해 다운로드하세요. (설치형 · 권장)
- 설치가 부담되면 → `ModooBom-Agent.zip` 을 받아 압축을 풀고 안의 `모두봄-에이전트.exe` 를 더블클릭해도 됩니다.

**2) 실행 → "Windows의 PC 보호" 창이 뜨면 (정상이에요!)**
- 처음 실행하는 앱이라 파란 경고창이 떠요. 나쁜 게 아니라, 아직 서명(유료 인증서)을 안 붙여서예요.
- 창에서 **[추가 정보]** 를 누르면 → 아래에 **[실행]** 버튼이 나와요. **[실행]** 을 누르세요.
  > (오픈소스 데모 앱이고, 개인정보는 서버로 안 보내고 내 컴퓨터에서만 처리해요.)

**3) 설치 완료 → "지금 모두봄 실행" 체크 → 끝!**
- 시작메뉴·바탕화면에 **"모두봄"** 아이콘이 생겨요. 다음엔 그 아이콘만 누르면 됩니다.

## ▶ 실행하면 이렇게 돼요
1. **검은 창**이 하나 뜨고(모두봄이 여기서 돌아가요 — **닫지 마세요!**),
2. **브라우저가 자동으로 열려요.** (안 열리면 브라우저에 `http://localhost:8000` 입력)
3. 새싹이(AI)랑 대화 → 복지 추천 → **[자동] 버튼**으로 서류 발급 → **폰에서 카카오 '인증 허용'만** 누르면 발급 완료!
4. 다 쓰면 **검은 창을 닫으면** 종료돼요.

## 🆕 최신 코드로 실행하면 이런 것도 있어요 (`run-local-app.bat` — git 최신이면 자동 반영)
- 🗂 **내 서류함**(발급/등록물 목록·자동첨부 후보 배지·삭제) + 📷 **서류 촬영→제출용 PDF** · 깨진 파일은 ⚠️ 표시 + **[🔁 지우고 다시 발급]** 한 번으로 정리·재발급
- 🔎 **자동발급 서류 직접 늘리기**: 목록에 없는 서류도 이름만 넣으면 앱이 정부24를 실측 조사 —
  발급 가능하면 **재시작 없이 바로** 자동발급 목록에 β로 추가돼요(실패는 정직하게 안내, 개인정보 없이 확인).
  **후보 칩 + [🚀 한번에 실측]**로 기본 후보 11종을 원클릭 일괄 확인
- 🔎 **자동신청도 직접 늘리기(β)**: 자동신청 버튼이 없는 정책 상세의 **[실측 확인]** — 앱이 복지로에서
  그 정책의 신청 상세를 실측으로 찾아내면 자동신청 버튼이 바로 생겨요. (복지로 특성상 온라인 신청형인지는
  첫 실행에서 확인 — 방문형이면 정직하게 안내하고 공식 링크로, [등록 해제]도 한 번에)
- 💬 **말로 발급까지**: 챗에 "등본 발급해줘" 한마디 → 버튼 한 번이면 서류 도우미로 이동해 그 서류의
  자동발급이 **바로 시작**돼요(등본·초본·가족관계 같은 생활어도 알아들음 · 📱 인증 승인만 직접).
  **"서류 전부 발급해줘"**라고 하면 원클릭 연쇄(부족분만·한 번 인증)가 통째로 시작되고,
  📞 **통화에서도 같은 말로** 똑같이 동작해요. 추천 카드에는 **🤖 자동신청** 표시가 붙어,
  상세를 열기 전에 '신청까지 자동'인 복지를 한눈에 알 수 있어요.
- 🤖 상태 스트립: **[발급 전 점검]**(브라우저·정부24/복지로 연결·폴더·디스크·**서류함 무결성** 6항목) · **[진단 복사]**(개인정보 없음)
  · 🩺 **조용한 자가점검**: 앱이 켜지면 스스로 한 번 점검 — 전부 정상이면 작은 ✓만, 문제가 있으면
  원인·조치를 **발급 시작 전에** 자동으로 보여줘요(버튼 누를 필요 없음)
- 📱 **인증 알림음**(+옵트인 **음성 안내** "휴대폰에서 인증 요청을 승인해 주세요") — 화면 안 봐도 폰 집을 타이밍
- 🔁 **이어보기**: 발급/신청 중 새로고침·화면 이동해도 돌아오면 자동 재연결
- ✅ 발급 성공은 자동으로 '발급 완료' 기억(재실행 시 중복 발급 안 함) · 신청 카드 '제출 완료 기록' 버튼
