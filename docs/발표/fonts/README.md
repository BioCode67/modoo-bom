# 발표자료 임베드 폰트

발표자료(본선-발표자료-초안.html)의 렌더 품질을 위해 웹폰트를 임베드합니다. 두 폰트 모두 SIL Open Font License 1.1로 재배포·임베드가 허용됩니다.

- **Pretendard** (가변, woff2) — 본문·숫자·라벨. 라이선스: OFL.txt · 출처: https://github.com/orioncactus/pretendard
- **Jua** (주아, ttf) — 제목·로고 등 디스플레이용 둥근 글꼴. 라이선스: Jua-OFL.txt · 출처: https://fonts.google.com/specimen/Jua

역할 분리: 제목·로고는 Jua로 친근하게, 본문·숫자는 Pretendard로 또렷하게.
