# 청년월세지원 — 한 사이클 데모 시나리오 (데스크탑 앱)

> 목표: **추천 → 담기 → 서류 자동발급 → 자동신청 → 사후관리** 한 바퀴가 실제로 도는 것을
> 인기 서비스 **청년월세지원**(복지로 WLF00004661) 하나로 보여준다.
> 웹(정적 배포)은 "정책을 모아 보여주고 정확한 신청 링크로 보내는" 데까지고,
> **실제 자동발급·자동신청은 이 데스크탑 앱**에서 동작한다(정부24 안티매크로를 실크롬으로 통과).

이 문서는 코드로 검증한 흐름만 적는다. 정부 사이트(정부24·복지로) 실제 화면 조작·카카오 인증은
발표 PC(Windows + 크롬 + 카카오톡)에서만 최종 확인된다.

---

## 0. 준비 (최초 1회)

필요: Windows(권장) / macOS, **Python 3.11+**, **Node.js 20+**, **크롬**, 폰에 **카카오톡**.

```bat
:: 저장소 최신화 — 아래 브랜치에 데모 사이클 수정이 들어있다
git fetch origin claude/project-status-summary-koj0ez
git checkout claude/project-status-summary-koj0ez
git pull

:: 최초 설치(가벼운 venv + 프론트 로컬 빌드) — 저장소 '루트'에서 더블클릭
setup-local.bat
```

> `setup-local.bat`은 `backend\venv-local` 생성 → `requirements-local.txt` 설치 →
> Playwright chromium 준비 → `frontend`에서 `npm run build:app`(로컬 앱 번들 `dist-app`)까지 한다.

---

## 1. 실행

```bat
:: 저장소 '루트'의 파일을 더블클릭 (backend 폴더가 아님)
run-local-app.bat
```

- `run-local-app.bat`은 **git HEAD가 바뀌었으면 `dist-app`을 자동 재빌드**한다
  (`git pull`로 최신 코드를 받은 뒤 그냥 더블클릭하면 최신 화면으로 뜬다 — stale 방지).
- 백엔드(localhost:8000)가 프론트까지 **동일 출처**로 서빙 → 브라우저 CORS/권한 프롬프트 0.
- 실행 후 자동으로 브라우저가 열린다. 안 열리면 `http://localhost:8000` 접속.
- 헬스 확인: `http://localhost:8000/api/health` → `capabilities.rpa: true` 이면 자동화 준비 완료.

## 2. 데모 한 사이클 (청년월세지원)

### ① 추천 — "내 상황"으로 청년월세지원을 찾는다
- 홈에서 **분석 시작** 또는 상단 한 문장 검색(음성도 가능):
  예) `27살 자취하는데 월세 지원 받을 수 있어?`
- 프로필(나이 27·1인가구·소득 중위 45% 정도)을 넣으면 결과 상단에 **청년월세지원**이 뜬다.
  (엔진 판정: 만 19~34세 청년 연령 기준 충족 → 우선순위 **높음**. `persona-golden` 테스트로 고정.)

### ② 담기 — 맘에 드는 서비스를 담는다
- 청년월세지원 카드의 **담기**(♡)를 누른다 → **나의 복지**에 들어간다.

### ③+④ 원클릭 하이라이트 — "🚀 전부 자동발급 + 자동신청까지" (권장 시연 경로)
- 서류 도우미의 **🚀 전부 자동발급** 버튼 아래 **"발급이 끝나면 청년월세지원 자동신청까지 이어서"**
  체크(기본 ON)가 있다 — 누르면 **한 번의 흐름**으로: 등본·가족관계·소득금액증명 순차 발급(각 인증은 📱승인만)
  → 방금 발급한 서류를 복지로 신청 양식에 **자동첨부** → **제출 직전 정지**. 상단 진행률 바가
  "3/4 완료 · 지금: 청년월세지원"처럼 전체 흐름을 보여준다. **이것이 대회 핵심 장면.**
- 리허설 직후엔 서류함에 유효한 발급물이 남아 버튼이 **"부족한 서류 n종만 자동발급"**으로
  줄어든다(정상 — 있는 서류는 건너뛰는 지능). 처음부터 전체 흐름을 다시 보이려면
  [다음 분 상담 시작]으로 서류함을 비우고 시작하면 된다.
- 아래 ③④는 단계별로 나눠 시연할 때의 경로다.

### ③ 서류 자동발급 — 정부24에서 대신 발급
- **나의 복지 → 서류 준비 도우미**로 가면 청년월세지원에 필요한 4종이 뜬다:
  **임대차계약서 · 주민등록등본 · 가족관계증명서 · 소득금액증명**.
- 자동발급 가능(정부24)인 **등본 · 가족관계증명서 · 소득금액증명** 카드의 **발급** 버튼을 누른다.
  - 실크롬이 정부24 로그인 → 간편인증 화면까지 자동 → **📱 카카오 [인증 허용]만 본인이** →
    발급 폼 자동 진행 → PDF가 **바탕화면\모두봄서류** 에 `서류명_이름_날짜.pdf`로 저장된다.
- **임대차계약서·신분증**은 정부가 발급하는 서류가 아니다(본인 보관본) → 카드의
  **📷 촬영** 또는 **📎 파일**로 등록한다.
  - **📷 촬영**: 카메라로 찍으면 자동 대비 보정 후 **제출용 PDF**로 만들어 서류함에 넣는다
    (신분증은 앞·뒤 2장, 계약서는 페이지마다 한 장 → 한 PDF로 합침). 썸네일에서 **↻ 회전**·**✂️ 자르기**
    (배경 넓으면 모서리 끌어 서류만)로 다듬을 수 있다. 촬영·보정·크롭·PDF 생성은 **전부 기기 안에서**(사진은 서버로 안 감).
  - **📎 파일**: 이미 가진 PDF·사진을 그대로 등록.
  - 둘 다 발급 폴더에 같은 이름 규칙으로 저장돼 **신청할 때 자동첨부 대상**이 된다.
    (웹에서는 로컬 폴더가 없어 PDF로 내려받아 신청 화면에서 직접 첨부)
- 서류 도우미 아래 **🗂 내 서류함**에서 발급/등록된 서류를 한눈에 본다 — **'첨부 후보' 배지**가 붙은
  서류가 신청 때 자동첨부 대상. 잘못 등록한 건 여기서 바로 삭제(2탭 확인).
- 상단 **🤖 에이전트 상태 스트립**에서 연결·버전·발급 슬롯 확인. **[발급 전 점검]** 한 번으로
  자동화 브라우저 기동·**정부24/복지로 연결**·발급 폴더·디스크를 점검한다(발표 직전 리허설용).
  문제가 생기면 **[진단 복사]**를 눌러 그대로 개발자에게 붙여넣으면 된다(개인정보 없음).
- 발급/신청 도중 **새로고침하거나 화면을 이동해도** 돌아오면 진행 상태가 자동으로 다시 연결된다.
  연쇄발급 중엔 상단에 **진행률 바(n/m·현재 단계)** 가 뜨고, 한 서류가 계속 막히면
  **[⏭ 이 단계 건너뛰기]**로 그 서류만 접고 다음 단계로 진행한다(전체 중단과 별개 — 데모 무정지 장치).
  📱 **인증 승인 차례가 되면 짧은 알림음**이 울린다(화면을 안 보고 있어도 폰 집을 타이밍을 앎).

### ④ 자동신청 — 복지로 신청 양식까지 자동
- 청년월세지원 **상세**를 열면 아래에 **에이전트 자동 신청** 카드가 있다
  (이번 수정으로, application이 "복지로 온라인 신청" 표시문자열이어도 **버튼이 정상 노출**된다).
- 내 정보(이름·생년월일·휴대폰) 확인 후 **에이전트로 신청 시작**.
  - 실크롬이 복지로 로그인 → 청년월세지원 신청 페이지 → **'신청하기'** → 양식에
    이름·생년월일·연락처 자동 입력 → **③에서 발급/등록한 서류를 첨부칸에 자동 첨부**
    (첨부칸 라벨과 서류명이 맞는 '확신 매칭'만 — 못 맞춘 칸은 어떤 파일을 올릴지 안내) →
    **제출 직전 정지**.
  - ※ 자동첨부는 **③을 먼저** 끝낸 뒤(같은 실행 세션·약 20분 이내 발급/등록분) 걸린다.
- **본인인증(카카오)과 최종 '제출'은 본인이 직접** 한다(명의도용·비가역 방지 — 의도된 안전장치).

### ⑤ 사후관리 — 신청을 기록하고 지켜본다
- 복지로 창에서 제출을 마치고 앱으로 **돌아오면** "「청년월세지원」 신청을 완료하셨나요?" 확인이 뜬다.
  **네, 신청했어요**를 누르면 상태가 **신청 완료**로 기록된다(누르지 않으면 기록하지 않음 — 날조 금지).
- 이후 **나의 복지**의 모니터링이 진행 점검·갱신 시기를 챙겨 알려준다
  (정부 서버 실시간 상태 조회는 본인 세션 없이는 불가 → 공식 조회 링크로 안내).

## 3. 정직한 자동화 경계 (심사위원에게 그대로 설명)

| 단계 | 자동 | 사람이 직접 |
|---|---|---|
| 추천·담기 | ✅ 전부 | — |
| 서류 발급 | ✅ 로그인·이동·폼 입력·저장 | 📱 카카오 인증 승인 |
| 자동신청 | ✅ 로그인·이동·양식 입력·서류 자동첨부 | 📱 카카오 인증 + 최종 **제출** |
| 사후관리 | ✅ 기록·점검·갱신 알림 | "네, 신청했어요" 확인 |

- **완전 무인 자동 제출은 설계상·법적으로 불가**(정부 본인인증 필수 + 비가역). human-in-the-loop가 정답.
- 개인정보(이름·생년월일·휴대폰·등록 파일)는 **이 PC에서만** 처리되고 서버로 나가지 않는다.

## 4. 안 터지게 — 실패 시 자동 폴백

- 어떤 서류 발급/신청이 정부 사이트 사정으로 막히면, 카드가 **정직한 오류 + 공식 페이지 링크**로
  자연스럽게 폴백한다(가짜 성공·좀비 로딩 없음). 데모가 통째로 멈추지 않는다.
- 발표 직전 리허설: `run-local-app.bat` 실행 → 서류 도우미 상단 **[발급 전 점검]** 클릭
  (브라우저·정부24/복지로 연결·폴더·디스크 5항목 자동 점검) → 전부 ✓이면
  등본 1건을 카카오 인증까지 **끝까지** 한 번 예행해 회선·세션 상태를 검증.
