# 모두봄 — 발표 핵심 포인트 (판정단 관점)

> 2026 AI·SW 중심대학 디지털 경진대회 SW부문 · 본선 발표용 뼈대.
> **원칙: 검증된 사실만, 과장 없이.** 실제로 되는 것과 사람이 해야 하는 것을 명확히 구분해 말한다
> (심사에서 "완전 무인 자동" 같은 과장은 오히려 감점 요인 — 우리는 정직함 자체를 강점으로 세운다).

---

## 1. 문제 (왜 필요한가) — "복지 사각지대"

- 받을 수 있는 복지를 **몰라서 못 받는다.** 정책은 정부24·복지로·지자체·민간재단에 **흩어져** 있고, 용어는 어렵다.
- **디지털 약자**(어르신)·**언어 장벽**(외국인·다문화)은 더 심하다.
- 설령 찾아도 **신청까지 가는 길**(서류 발급→양식 작성→제출)이 복잡해 중도 포기한다.

## 2. 해결 (한 문장) — 모두봄

> **"내 상황을 한 문장(또는 대화)으로 말하면, AI가 5,300여 건 중 내 것을 찾아주고,
> 서류 발급·복지 신청까지 실제로 대신 진행해 주는 개인 복지 에이전트."**

## 3. 차별점 3가지 (심사 핵심 — 전부 실동작 검증)

### ① 온디바이스 다국어 AI 의미 검색 (프라이버시·혁신)
- 브라우저에서 **직접 도는 신경망 임베딩**(`multilingual-e5-small`)으로 복지를 **의미로** 매칭.
  한국어·English·Tiếng Việt 교차검색(외국인 사각지대).
- **개인정보가 서버로 안 나간다.** 정책 벡터는 빌드 시 사전계산 → 런타임은 질의만 기기에서 임베딩.
- 모델 없이도 되는 **"AI로 비슷한 복지"**(사전계산 임베딩만) — *실측: 청년월세지원 → 청년월세한시특별지원·
  청년주거급여·청년구직지원 등 의미로 정확히 랭킹.* 모델 로드 실패(오프라인)에도 **키워드로 정직 폴백**.

### ② 정직한 "실제" 자동화 (RPA) — 안내가 아니라 대행
- 대부분의 복지 서비스는 "링크만 던진다". 모두봄은 **정부24·복지로를 실제 브라우저로 조작**해
  로그인→이동→양식 자동작성→**서류 자동 첨부**까지 진행.
- **📷 서류 촬영**: 자동발급 안 되는 서류(신분증·임대차계약서)를 폰으로 찍으면 **자동 보정 후 제출용 PDF**로
  만들어 신청에 자동첨부(전부 온디바이스). *실측: 웹 다운로드·데스크탑 등록·모바일 촬영 전부 동작.*
- **정직한 경계(강조점):** 본인인증(카카오)과 **최종 제출**은 **반드시 사람이** — 명의도용·비가역 방지.
  "완전 무인"은 설계상·법적으로 불가하며, 우리는 그걸 **의도된 안전장치**로 설명한다.

### ③ 완결된 한 사이클 + 오프라인 PWA
- **추천 → 담기 → 서류 발급/촬영 → 자동 신청 → 사후관리 모니터링** 한 바퀴가 실제로 돈다.
- **🚀 원클릭 연쇄(하이라이트)**: '전부 자동발급' 한 번으로 **등본→가족관계→소득금액증명 순차 발급 →
  방금 발급분을 복지로 신청 양식에 자동첨부 → 제출 직전 정지**까지 한 흐름. 상단 진행률 바(n/m·현재 단계),
  새로고침해도 **자동 재연결**(이어보기). *E2E 계약 테스트로 고정.*
- **PWA 오프라인**: 서비스워커 캐시로 **연결 없이도 앱이 뜬다** — 통신 취약 계층까지 닿는다. *실측 확인.*

## 4. 라이브 데모 (청년월세지원 — 인기 서비스 하나로 끝까지)

1. 한 문장: *"27살 자취하는데 월세 지원 받을 수 있어?"* → **20개 추천, 청년월세지원 강력추천**
2. 상세: **🤖 AI로 비슷한 복지**(의미 랭킹) + 필요서류 4종 + 신청 키트(내 정보 미리채움)
3. 임대차계약서는 **📷 촬영→보정→PDF** 등록(🗂 내 서류함에 '첨부 후보' 배지)
4. **🚀 원클릭**: "전부 자동발급 + 자동신청까지" → 등본·가족관계·소득금액증명 순차 자동발급(📱카카오 승인만)
   → 복지로 양식 작성·**서류 자동첨부** → **제출 직전 정지**(본인 확인) — 대회 핵심 장면
5. **사후관리**: 복귀 확인("신청 완료하셨나요?") → '진행 점검' 알림 (상태 날조 없이 공식 조회 안내)

> 데스크탑앱(`run-local-app.bat`)에서 실제 정부 RPA까지 시연. 상세 대본은 `docs/청년월세-데모-시나리오.md`.

## 5. 임팩트

- **발견성**(AI 의미검색·다국어) + **실행성**(실제 RPA·촬영) + **접근성**(오프라인·큰글씨·고대비·음성·TTS)를
  한 번에 → 복지 사각지대(정보·언어·디지털·실행)의 **네 겹을 동시에** 낮춘다.
- 데이터: 정부·지자체·민간 **약 5,300건** 실데이터(가짜 미생성 원칙).

## 6. 기술 스택 & 품질

- **Frontend**: React 18 · Vite · TS · Tailwind · transformers.js(온디바이스 AI) · R3F(3D) · zustand · PWA
- **Backend/Agent**: FastAPI · LangGraph 10노드 · ChromaDB RAG · **Playwright RPA**(정부24·복지로·건보·고용24)
- **품질 게이트(전부 통과)**: `tsc` · ESLint(0) · **vitest 728** · `build` · **pytest 130+** ·
  **실브라우저 E2E 5종**(smoke·flows·camera·mobile·**desktop**) — 웹·데스크탑앱·모바일 3폼팩터 실측.
- 데스크탑앱 신뢰 장치: 🤖 상태 스트립([발급 전 점검] 5항목·🩺 진단 복사)·📱 인증 알림음+🔊 음성 안내(옵트인)·
  ⏭ 개별 단계 건너뛰기·🔁 이어보기(새로고침 복원)·여정 종결 요약·✅ 검증형 리셋(상담소 다인 사용) —
  전부 실브라우저 회귀(desktop-smoke 16종)로 고정.

## 7. 정직한 한계 (먼저 밝히면 신뢰가 된다)

| 하는 것(자동) | 사람이 하는 것 |
|---|---|
| 추천·검색·양식 작성·서류 발급/촬영·자동첨부·사후 알림 | 📱 카카오 본인인증 · 최종 **제출** 클릭 |

- 클라우드 데이터센터 IP는 정부24 안티매크로에 막힌다 → **사용자 PC(데스크탑앱)** 에서 도는 게 정답(주민 IP).
- 완전 무인 자동제출은 불가(정부 본인인증 필수·비가역). **human-in-the-loop가 설계적 정답.**
