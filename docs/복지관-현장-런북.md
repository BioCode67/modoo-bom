# 복지관 현장 런북 — 어르신 실사용 지원 (월·화 방문용)

> 목표: 어르신 한 분당 10~15분 안에 "복지 찾기 → 서류 자동발급 → 신청 → 기록"까지.
> 자동화 범위: 본인인증(폰에서 허용 탭)과 최종 제출 확인만 본인, 나머지는 전부 자동.
> 정부24 담당 유선 확인(2026-07): 정상적 발급·신청 목적의 자동화 접근은 허용.

## 전날 준비 (노트북 1대 기준, 30분)

1. 모두봄 데스크탑 앱 최신본 설치 — https://github.com/BioCode67/modoo-bom/releases 의 `ModooBom-Setup.exe`
   (SmartScreen 뜨면 [추가 정보]→[실행]). 이미 설치돼 있으면 재설치로 최신화.
2. 앱 실행 → 브라우저 자동 오픈 확인 → 서류 도우미에서 **본인 정보로 등본 1회 발급 리허설**
   (전 과정 확인: 자동입력→폰 인증→PDF가 바탕화면 `모두봄서류`에 저장).
3. 신청 리허설 1회: 아무 정책 [신청하기] → 복지로 로그인→양식 자동작성→**발급 서류 자동첨부**까지 확인.
   양식은 제출하지 말고 창 닫기.
4. 노트북 체크: 전원 어댑터, 크롬 로그인 상태 아님(시크릿 아님·일반 창), 화면 배율 125%(어르신 가독).
5. 백업: 폰 핫스팟(복지관 와이파이 불안 대비), 수동 발급 경로 숙지(정부24 직접).

## 어르신 1명 상담 흐름 (10~15분)

| 단계 | 하는 일 | 누가 |
|---|---|---|
| ① 2분 | 대화로 상황 듣기 → 홈에서 한 문장 입력("혼자 살고 소득이 적어요") 또는 새싹이와 대화 | 직원이 입력 |
| ② 2분 | 결과 확인 → 받을 만한 것 [담아두기] (현금성 위주 2~3개) | 함께 |
| ③ 1분 | 서류 도우미 → 자동입력 추가정보에 성함·생년월일·휴대폰 입력 + **본인인증 앱 선택**(카카오 없으면 '통신사 PASS') | 직원이 입력, 어르신 확인 |
| ④ 3분 | [자동발급] 클릭 → 화면 자동 진행 → **어르신 폰에 인증 알림** → "어르신, 폰에 뜬 [인증 허용]만 눌러주세요" | 인증만 어르신 |
| ⑤ 3분 | 필요 시 [신청하기] → 복지로 자동 이동·작성·**서류 자동첨부** → 내용 같이 읽고 **어르신 확인 후 제출 버튼은 어르신 손으로** | 제출만 어르신 |
| ⑥ 1분 | 발급 PDF 위치 안내(바탕화면 모두봄서류) 또는 복지관 프린터로 인쇄 | 직원 |
| ⑦ 30초 | **[다음 분 상담 시작] 버튼**(서류 도우미의 자동입력 폼 아래) → 이전 분 정보 전체 삭제 확인 | 직원 필수! |
| ⑧ 30초 | **기록지 1행 작성**(`복지관-현장-기록지.md` — 연령대·발급·인증수단·시간) → 산출물 실사용 증거가 됨 | 직원 |

## 인증이 안 될 때 (현장 최다 이슈)

- **카카오톡이 없다** → 인증 앱을 '통신사 PASS'로 바꾸고 재시도(어르신 폰에 PASS 앱 확인 — 통신 3사 대부분 설치됨).
- **PASS도 없다** → 네이버·토스 순으로 시도. 전부 없으면 그 어르신은 수동 경로(복지관 직원 대행 방문 안내).
- **폰 알림이 안 온다** → 폰 잠금 해제 후 해당 앱을 직접 열어보게(알림함에 있음). 1분 내 재시도.
- 인증 5분 초과로 시간 만료 → 같은 버튼으로 처음부터 재시도(자동입력이라 30초면 재도달).

## 반드시 지킬 것 (프라이버시)

- 어르신 한 분 끝날 때마다 **[다음 분 상담 시작]** — 이전 분 이름·생년월일·연락처·기록이 전부 지워진다.
- 발급된 PDF는 그 자리에서 인쇄/전달 후 **바탕화면 모두봄서류 폴더 비우기**(하루 끝나면 휴지통 비우기까지).
- 노트북을 자리에서 비울 땐 화면 잠금(Win+L).
- 어르신 정보는 종이에 적지 말 것 — 화면에만.

## 속도 튜닝 (현장에서 필요 시)

- 발급이 너무 빨라 정부 사이트가 막는 느낌이면: 앱 종료 → `RPA_SLOW_MO=250` 환경변수로 재실행(기본 120).
- 신청 검토 시간이 더 필요하면: `RPA_REVIEW_WINDOW=1200`(기본 600초=10분).

## 서류 15종 중 신규 4종 참고 (07-11 확장)
국세 납세증명서·출입국사실증명·병적증명서·건강보험료 납부확인서는 정부24 페이지 실측(즉시발급형)으로
추가됐고 로그인·인증까지의 흐름은 검증됐지만, **인증 후 발급폼 완주는 리허설에서 1회 확인**을 권장.
현장 주력은 검증 완료된 등본·수급자증명·한부모증명 등 기존 서류로.

## 안 되는 것 (미리 알고 가기 — 정직하게 안내)

- 최종 '제출' 버튼과 본인인증은 법적으로 본인이 눌러야 한다(우리 설계 원칙이기도).
- 신청 자격 심사는 지자체가 하므로 현장에서 결과가 나오지 않는다 — "며칠 뒤 문자·전화로 결과 옵니다" 안내.
- 일부 복지는 온라인 신청이 없다(방문 전용) — 그 경우 '주민센터 방문 키트'(정책 상세에서 인쇄)를 뽑아드리기.
