# 모두봄 — 데모 발표 대본 (약 4~5분)

> 시연 전 필수: ① `run-windows.bat` 실행(백엔드 8000 + 프론트 5173) ② **AI 토글 1회 켜서 모델 프리워밍**(캐시) ③ RPA 데모는 `localhost:5173`에서(배포 사이트는 브라우저 정책상 로컬 감지 불안정).

---

## 0. 오프닝 (20초)
> "복지는 사이트마다 흩어져 있고, 용어는 어렵고, 외국인·어르신에겐 더 멀죠. **모두봄은 브라우저에서 직접 도는 AI가, 서버도 회원가입도 없이, 어떤 언어로든 전국 복지를 찾아 신청까지 이어주는 개인 복지 AI Agent입니다.**"

## 1. 첫인상 — 홈 (20초)
- 라이브 사이트 오픈 → 3D 새싹 마스코트 히어로, "전국 5,000+ 복지" 강조.
- 온보딩 첫 항목 **"🌍 다국어 AI 의미 검색"** 짚기.

## 2. ⭐ 헤드라인 — 온디바이스 다국어 AI (90초) ★가장 중요
- 홈 "다국어 AI 의미 검색" 카드 → **[지금 체험하기]** 클릭 → 탐색에 AI 모드 자동 ON.
- **영어로 입력**: `I lost my job and need help` → "🇬🇧 English 감지" 배지 + **AI 답변 카드**(요약) + 긴급복지·국민취업지원 결과.
- **베트남어로 입력**: `Tôi là người khuyết tật` → 장애인연금·발달재활 매칭.
- 강조 포인트 3가지:
  1. **"이 AI 모델은 서버가 아니라 지금 이 브라우저 안에서 직접 돕니다. 입력 정보가 서버로 전송되지 않아요."**(프라이버시)
  2. **"영어·베트남어로 물어도 한국 복지를 의미로 찾아줍니다."**(외국인·다문화 사각지대)
  3. **🔊 음성으로 듣기** 눌러 AI가 답을 읽어주는 것 시연(대화형).

## 3. 맞춤 분석 (40초)
- "복지 찾기" → 한 문장(예: "72세 혼자 사는데 소득이 적어요") → 맞춤 복지 + **예상 금액** + 우선순위 + 필요 서류.
- "나의 복지"에 담기 → 현금성 혜택 합산·비교·사후관리 모니터링.

## 4. 실제 정부 자동화 — RPA (60초)  ※localhost:5173에서
- 복지 상세 → **"에이전트로 신청/자동발급"** 버튼(로컬 에이전트 감지되어 활성).
- 클릭 → **Edge 창이 열려 정부24 로그인·간편인증까지 자동으로 이동** → 카카오 본인인증 폼 도달.
- 강조: **"로그인·이동·양식은 AI가 자동으로. 본인인증(카카오 폰)만 사용자가 — 완전 무인 대리인증은 명의도용이라 의도적으로 배제한, 안전하고 정직한 설계입니다."**
- (다이어그램 `diagram3-발급자동화.png`로 "8단계 → 1단계" 설명 가능)

## 5. 마무리 — 완성도·정직성 (30초)
- "정적 배포라 서버 비용 0, 즉시 체험. 개인정보는 기기 내에만. 데이터는 5,185건 실데이터, 가짜 없음."
- "프론트 테스트 168 / 백엔드 13 통과, 접근성(큰글씨·고대비·음성·다국어)까지."
- **"복지 사각지대를 AI Agent로 좁히는 것 — 그게 라이프스타일 혁신이라고 생각합니다."**

## 예상 Q&A
- **Q. AI가 서버 없이 어떻게?** → transformers.js로 임베딩 모델을 브라우저에서 WASM/WebGPU로 실행. 정책 벡터는 빌드 시 사전계산. 질의만 즉석 임베딩.
- **Q. 다국어는 번역인가?** → 아니요. **다국어 임베딩의 교차언어 의미공간**을 이용해 번역 없이 의미로 매칭(환각·오역 없음).
- **Q. 발급이 완전 자동인가?** → 인증 직전까지 자동, 카카오 본인인증만 사용자. 법적·비가역 절차라 대리 불가(정직).
- **Q. 정확도?** → 시드는 규칙 기반 정밀 판정, 공공데이터는 의미 매칭. 금액·자격은 2026 공식 출처 검증, 최종 확인은 복지로/129 안내.
