# 발표 대본 — "김복순 님의 3분" (본선 발표 + 30초 투표 동선)

> 원칙: 기능 나열 금지. **한 사람의 이야기**로 처음부터 끝까지. 모든 수치는 라이브 화면과 동일(실측).
> **본선 심사기준 매핑(FAQ 확정 — 창의30·구현완성도25·편의성20·주제적합15·사용가능성10)**:
> [0:20 찾기]=창의성(민간재단·온디바이스) · [0:50 챗]=주제적합성(에이전트 루프)+편의성(말로 시킴) ·
> [1:20 신청]=창의성+구현완성도(실브라우저 발급 완주) · [2:10 신뢰]=구현완성도(테스트 수)+사용가능성(라이브·PWA).
> **편의성 20점 전용 20초를 놓치지 말 것**: 큰글씨·고대비·음성입력·TTS·7개 언어를 화면 토글로 한 호흡에 시연.
> 발표자료는 **PDF만 허용**(PPT 불가) · 발표 한국어 · 참석 최대 2명(발표자 1명 지정).
> 시연은 전부 라이브 사이트(https://biocode67.github.io/modoo-bom/)에서 — 준비물: 노트북(크롬+확장), 폰(카카오톡), QR 슬라이드.

## A. 본선 3분 대본 (발표 2:30 + 여유 0:30)

**[0:00–0:20] 문제 — 한 사람** *(슬라이드: 김복순 사진 실루엣 한 장)*
> "일흔둘, 혼자 사시는 김복순 님. 기초연금은 받지만, 자신에게 **월 64만원어치의 권리**가 더 있다는 건 모르십니다.
> 몰라서 못 받는 복지 — 정부·지자체·민간재단에 **5천 건 넘게 흩어져** 있고, 말은 어렵고, 신청은 더 어렵기 때문입니다."

**[0:20–0:50] 찾기 — 한 문장이면 됩니다** *(라이브: 홈 → 한 문장 입력)*
> "모두봄은 AI 에이전트입니다. 회원가입도 서버도 필요 없습니다."
> ⌨️ **"72세 혼자 사는데 소득이 적어요"** 입력 → 결과 화면.
> "핵심 현금지원 **월 최대 63만 9천원**. 그리고 아래 — 정부 데이터 어디에도 없는 **민간재단 💝**: 심장 수술비, 위기가정 지원까지. 저희가 재단 하나하나 실측 검증해 담았습니다."

**[0:50–1:20] 이해와 행동 — 에이전트가 대신** *(라이브: 챗)*
> 챗 열기 → *(먼저 브리핑이 뜨면)* "열자마자 제가 시키지 않아도 '지금 챙길 일'부터 보고합니다."
> ⌨️ **"다 담아줘"** → "말 한마디로 담았습니다." ⌨️ **"서류 뭐 필요해?"** → "필요 서류를 모아 '2곳에서 필요'까지 계산합니다.
> 지식이 필요한 질문은 **AI가 실시간으로**(🧠 라벨 · Gemini, 실패 시 자동 폴백), 담기 같은 행동은 **기기 안 에이전트가** — 개인정보는 서버로 가지 않습니다."

**[1:20–2:10] 신청 — 여기가 다른 서비스와 갈리는 지점** *(라이브: 데스크탑앱 🚀 원클릭 연쇄)*
> "다른 서비스는 여기서 링크를 줍니다. 모두봄은 **직접 갑니다** — 그것도 **버튼 한 번으로 끝까지**."
> **[🚀 전부 자동발급 + 자동신청까지]** 클릭 → 진행률 바(n/m) 등장 → 정부24 자동 진행 →
> *(📱 알림음이 울리면 폰 들어 보이며)* "지금 저 소리가 '폰 잡으세요' 신호입니다. 본인인증만 제가 —
> 이건 법이 사람에게 요구하는 유일한 단계고, **그래야 옳습니다**" → 카카오 승인 → 발급 PDF 저장 →
> 이어서 **복지로 신청 양식 자동작성 + 방금 발급한 서류 자동첨부** → **제출 직전 정지**.
> "발급부터 신청서 첨부까지 왔는데, 제가 누른 건 버튼 한 번과 폰 승인뿐입니다. **최종 제출은 멈춰 섭니다** — 사람 몫이니까요."
> *(한 줄 강조)* "시연용 목업이 아니라 **실제 정부24·복지로를 그대로 조작**합니다. **복지로 딥링크를 가진 정책이면 처음 보는 복지도 같은 흐름으로** 이어집니다."
>
> ⏱ **시간 제어 전술**: 리허설 때 가족관계·소득금액을 미리 발급해 두면 앱이 '발급 완료'로 기억 —
> 라이브에선 **등본 1종 발급 + 자동신청**만 연쇄돼 ~90초에 끝난다(전부 실기능, 연출 아님).

**[2:10–2:30] 신뢰 — 왜 믿어도 되는가** *(슬라이드: 숫자 4개)*
> "**약 5,300건 실데이터 · 자동테스트 840여 개(프론트 717·백엔드 130+) · 실브라우저 E2E 5스위트(웹 10여정 + 데스크탑 14종) · 환각 0 설계.**
> 저희는 과장을 코드로 막았습니다 — 심사형 민간지원을 '자격 있음'으로 표시하는 것조차 테스트가 거부합니다.
> 김복순 님 같은 분이 전국에 수백만입니다. 모두봄이 그분들의 **몰랐던 권리**를 찾아드리겠습니다."

## B. 참가자 투표용 30초 동선 (부스/QR)

1. QR 스캔 → 라이브 접속 (3초)
2. 홈에서 예시 문장 탭: **"퇴사하고 일자리 찾는 청년이에요"** (5초)
3. 결과: 청년 정책 + 장학재단 💝 등장 (10초)
4. 멘트 한 줄: **"복지로에 없는 민간 장학까지, 로그인 없이, 내 폰 안에서."**
5. (여유 시) 챗에 "다 담아줘" — 웃음 포인트.

## C. 시연 리스크 큐시트

| 상황 | 대응 |
|---|---|
| 행사장 와이파이 불안 | PWA 오프라인(사전 1회 로드) + 시드 190건으로 분석·챗 전부 동작 |
| 정부24 응답 지연 | "정부 서버가 붐비네요 — 실제 서비스답죠" + 사전 녹화 15초 백업 영상 |
| 자동클릭 미동작 | 화면 안내대로 직접 클릭(설계된 폴백) — "멈춘 게 아니라 사람 차례입니다" |
| 연쇄 중 한 서류만 막힘 | 진행률 바의 **[⏭ 이 단계 건너뛰기]** — 그 서류만 접고 다음 단계 계속(데모 무정지) |
| LLM 백엔드 미연결 | 챗은 규칙 폴백으로 동일 동작 — 언급 없이 진행 (데모 전 라이브 접속 1회로 Render 워밍 권장) |
| 시간 초과 임박 | 1:20 신청 시연을 백업 영상으로 대체(-30초) |

## D. 발표 전 체크리스트
- [ ] 데스크탑앱 `run-local-app.bat` 실행 → 서류 도우미 **[발급 전 점검]** 5항목 ✓(브라우저·정부24/복지로 연결·폴더·디스크)
- [ ] 리허설 발급으로 가족관계·소득금액 '발급 완료' 기억시켜 두기(라이브는 등본+신청만 연쇄 — 시간 제어)
- [ ] 스트립 **[🔊 인증 음성 안내]** 취향대로(알림음은 기본) · 인증정보 폼은 발표 직전 입력(새로고침 시 비워짐 — 디스크 미저장 설계)
- [ ] Render 백엔드 wake(콜드스타트 방지, 5분 전 /api/health 1회)
- [ ] 확장 최신 로드 + 정부24 사전 로그인
- [ ] AI 검색 모델 프리워밍(토글 1회)
- [ ] 폰 카카오톡 로그인·알림 확인
- [ ] 백업 영상 2개(발급 완주 15초·챗 시연 10초) 로컬 저장
