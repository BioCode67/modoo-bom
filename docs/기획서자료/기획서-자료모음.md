## 1. 한 줄 정의
> **나이·소득·상황(또는 어떤 언어의 한 문장)만 알려주면, 브라우저에서 직접 도는 AI가 전국 5,000여 복지에서 내게 맞는 혜택을 찾아 신청·발급까지 이어주는 개인 복지 AI Agent.**

## 2. 핵심 차별점 (심사 포인트)

| # | 차별점 | 내용 | 왜 대단한가 |
|---|--------|------|-------------|
| 1 | **온디바이스 다국어 AI 의미검색** | 브라우저에서 직접 실행되는 신경망 임베딩(multilingual-e5-small)으로 5,185건을 *의미*로 매칭 | 서버·회원가입 0, 한/영/베트남/중/일 **교차검색** — 외국인·다문화 복지 사각지대 정면 공략 |
| 2 | **AI 대화형 답변 + 음성** | 검색이 아니라 "이해→요약 답변"(환각 없이 검색결과 기반) + 자국어 음성 대화 | 진짜 AI Agent 경험, 접근성(어르신·시각장애·외국인) |
| 3 | **실제 정부 RPA 자동화** | 정부24·복지로를 실제 브라우저로 자동 조작, 발급 인증 지점까지 몰아줌 | 목업이 아닌 **진짜 자동화**, 본인인증만 사용자(법적·비가역) |
| 4 | **프라이버시 우선** | 입력·AI 추론 전부 기기 내, 서버 전송 0 | 민감한 복지 정보 보호 |

## 6. 서류 발급 자동화 (RPA)

- 정부24 주민등록등본 기준: **기존 8단계 수동 → 모두봄은 폰 승인 1단계만 본인.**
- 자동: 로그인·간편인증 이동·정보입력·발급 양식·PDF 저장.
- 본인: 카카오 폰 인증(법적 강제, 명의도용 방지 — 완전 무인 대리인증은 설계상 배제).
- **크롬 확장(MV3)으로 배포 사이트에서도 동작** — 서버·Python·로컬 설치 0, 개인정보 브라우저 밖 무전송.
  서류 13종 + 복지로·장학재단 신청 딥링크 일반화. 정부 버튼의 isTrusted 게이트는
  debugger 프로토콜 '진짜 클릭'으로 돌파(기술 난제 해결 스토리 — 발표 포인트).
- → `diagram3-발급자동화.png`
