## 0. 시연 30분 전 — 프리워밍 (⚠️ 이것만은 꼭)

| # | 할 일 | 이유 |
|---|------|------|
| 1 | 배포 사이트를 한 번 열고 **챗에 아무거나 질문** | 백엔드(Render 무료)가 15분 유휴 시 잠들어 첫 요청이 ~50초. 미리 깨워두면 시연 땐 즉시 응답 |
| 2 | **탐색 → 'AI 의미 검색' 토글 1회** | 온디바이스 AI 모델(~128MB) 첫 로드 ~1분. 미리 받아두면 시연 땐 즉시 |
| 3 | **시크릿 창**으로 열기 (또는 강력 새로고침 `Ctrl+Shift+R`) | 옛 PWA 캐시가 아닌 최신 버전 보장 |
| 4 | 백업 영상 2개(10노드 분석 15초 · 다국어 검색 10초)를 폰에 저장 | 현장 네트워크 사고 대비 |

> 24시간 유지 팁: uptime 모니터가 이미 백엔드를 10분마다 핑하도록 설정돼 있어 **평상시엔 깨어 있음**. 그래도 시연 직전 1번 더 확인 권장.

## 1. 핵심 3장면 (여기서 심사위원이 놀란다)

시간이 없으면 이 3개만: **① 10노드 에이전트 → ② 다국어 온디바이스 AI → ③ 오프라인.**

### 장면 ① — "진짜 AI 에이전트가 판단한다" (10노드 스트림)
1. 상단 **복지 찾기** → **직접 입력** 탭 → **독거 어르신** 페르소나 클릭
2. 화면: **"⚙️ AI 에이전트가 추론 중 (n/10)"** — 프로필 분석 → 정책 검색(RAG) → 자격 판별 → **재판정 검증 루프** → … → 최종 안내까지 10개 노드가 순차 점등
   - *멘트:* "정해진 매크로가 아니라, 실제 LangGraph 10노드 에이전트가 클라우드에서 실시간으로 판단합니다."
3. 결과: **"김복순 님이 받을 수 있는 복지는 37개예요!"** · **핵심 현금지원 월 64만원** · 강력추천 16개
   - 실측 추천: **기초연금 · 주거급여 · 전기요금 복지할인 · 노인 일자리 · 저소득 어르신 틀니 지원** 등 (전부 어르신 정확 매칭)
4. 정책 하나 클릭 → 상세에 **"내가 받을 수 있는 이유"** + 체크리스트: **✓ 만 72세·어르신 대상  ✓ 소득 하위 25%·소득 조건 부합**
   - *멘트:* "경쟁 앱은 조건을 나열만 하지만, 우리는 내 정보와 대조해 '왜 되는지'를 투명하게 보여줍니다."

### 장면 ② — "어떤 언어로 말해도 뜻으로 찾는다" (온디바이스 다국어 AI · 헤드라인)
1. **정책 탐색** → **AI 의미 검색 ON** 토글 (다국어 배지)
2. 검색창에 영어로: **`I lost my job and need money`**
3. 화면: 언어 자동감지 🇬🇧 → 결과에 **국민취업지원 · 구직활동 지원 · 긴급복지** 등
   - *멘트:* "번역이 아니라 브라우저 안에서 도는 신경망이 '뜻'으로 매칭합니다. 서버 전송 0 — 외국인·다문화 사각지대를 정면으로 풉니다."
4. (선택) 예시 칩 `Tôi cần hỗ trợ tiền thuê nhà`(베트남어) 클릭 → 주거 복지

### 장면 ③ — "인터넷을 꺼도 된다" (오프라인 PWA)
1. (시연 가능 시) Wi-Fi 끄기 → 새로고침 → **앱이 그대로 뜸**
2. 오프라인 상태로 한 문장 분석 → **결과 정상 표시** (실측: 오프라인에서 "받을 수 있는 복지 37개" 나옴)
   - *멘트:* "설치도 로그인도 필요 없고, 인터넷이 끊겨도 됩니다. 개인정보는 애초에 서버로 안 나갑니다."

## 2. 전체 시연 동선 (3~4분, 클릭 → 실제 화면)

| 순서 | 클릭 | 실제로 뜨는 것 (실측) | 멘트 포인트 |
|---|---|---|---|
| 1 | 홈 진입 | 3D 새싹 마스코트 + "받을 수 있는 복지 혜택, 모두 찾아드릴게요" + 다국어 예시 칩 | "회원가입·설치 0, 개인정보는 내 기기에만" |
| 2 | 홈 입력창에 **"72세 혼자 사는데 소득이 적어요"** → 엔터 | 10노드 스트림 → 37개 결과 · 월 64만원 | 장면 ① |
| 3 | 결과에서 정책 클릭 | "내가 받을 수 있는 이유" + 자격 체크리스트 | 투명한 AI |
| 4 | 하단 스크롤 → **우리 동네 복지** | 한국 지도(시도별 색 진하기) + 내 지역 강조 | "지자체 4,600여 건까지 — 정부 지원만 보면 놓쳐요" |
| 5 | **나의 복지** → 관심 분야 알림 | 분야 구독 → "받을 수 있는데 안 담은 N건" 능동 안내 | "웰로식 분야 구독 + 사후관리" |
| 6 | **정책 탐색** → AI 의미 검색 | 영어→한국어 교차검색 | 장면 ② (헤드라인) |
| 7 | (여유 시) 챗봇 | 실시간 Gemini 답변 | "진짜 LLM 답변, 실패 시 Groq 자동 폴백" |
| 8 | (여유 시) Wi-Fi off | 오프라인 동작 | 장면 ③ |

## 3. 리스크 큐시트 (실측 기반 폴백)

| 상황 | 실제 동작 (확인됨) | 대응 |
|---|---|---|
| 백엔드가 잠들어 첫 챗/분석이 느림 | 화면에 "AI 에이전트를 깨우는 중…" 표시 후 **45초 내 결과**(클라이언트 엔진 폴백). 멈추지 않음 | 프리워밍으로 예방. 그래도 느리면 "지금 클라우드를 깨우는 중"이라 설명 |
| 현장 네트워크 불안정 | 분석·탐색은 **오프라인에서도 동작**(클라이언트 엔진 + 캐시) | 당황 말고 계속 진행. 정 안 되면 백업 영상 |
| Gemini 쿼터 소진 | **Groq로 자동 폴백**, 그래도 안 되면 규칙 기반 답변 | 티 안 남 — 그대로 진행 |
| 정책 상세의 서류 자동발급(RPA) | 배포(정적)에선 미동작 → **공식 링크 안내로 폴백** | "실제 자동발급은 PC 로컬 에이전트/확장에서 — 본인인증은 안전상 사용자 몫" |

## 4. 예상 Q&A (실측 근거 포함)

**Q. 데이터는 진짜인가요? 몇 건?**
A. 한국사회보장정보원 공공데이터 + 보건복지부 검증 시드 = **약 5,250건 실데이터**(가짜 미생성). 탐색 상단에 실시간 건수 표시.

**Q. 개인정보는 안전한가요?**
A. 입력·AI 추론 전부 **기기 안에서만**. 서버 전송 0. 회원가입도 없음. (오프라인 동작이 그 증거)

**Q. "AI 에이전트"가 실제로 뭘 하나요?**
A. LangGraph 10노드가 검색·자격판별·재판정 루프·가이드·발급까지 자동 수행. 화면에 실시간으로 보임. 정부24 실제 서류발급까지(로컬).

**Q. 자격 판정을 어떻게 믿나요?**
A. 2026 정밀 선정기준으로 판정하고, **"왜 되는지"를 내 정보와 대조해 체크리스트로** 보여줌. 심사·선발형(민간재단 등)은 '자격 있음'으로 표시하지 않도록 **테스트로 강제**(과장 차단).

**Q. 경쟁 서비스(복지로·보조금24·웰로)와 뭐가 다른가요?**
A. 무로그인·통합·온디바이스 다국어·오프라인·실제 RPA·투명한 근거 — 이 조합은 기존에 없음. (경쟁 앱은 로그인 벽 + 서비스 분절 + 한국어 편중)
