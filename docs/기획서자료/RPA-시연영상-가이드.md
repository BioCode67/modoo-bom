# 실제 자동발급 시연 영상 — 60초 촬영 가이드

> 심사평 #4: "킬러 기능(실제 RPA)이 라이브에서 안 보인다 → 화면녹화를 홈에 넣어라."
> 이 영상 하나면 아무도 설치 안 해도 킬러 기능을 봅니다. 화면녹화(OBS/곰녹화/Win+G) + 스마트폰 준비.

## 사전 준비 (촬영 5분 전)
- `run-agent-cdp.bat` 한 번 리허설(카카오 승인 흐름 확인) → `backend/agent_profile.json`에 본인정보 저장돼 있게.
- 자동화용 크롬 창은 미리 닫아두고, 화면녹화 시작 후 깨끗하게 실행.
- 데스크톱에 `모두봄서류` 폴더가 비어있게(발급 결과가 새로 떨어지는 걸 보여주려고).

## 촬영 컷 (총 ~60초)

| 시간 | 화면 | 자막/내레이션 |
|---|---|---|
| 0–8s | 배포 사이트 → 나의 복지 → 서류 준비 도우미 → **[등본 자동발급]** 클릭 | "복지를 찾았으면, 서류도 AI가 대신 발급합니다" |
| 8–20s | 새 크롬 창이 열리고 **정부24 자동 로그인 → 간편인증 창 자동 오픈 → 이름·생년월일·휴대폰·전체동의 자동 입력** | "정부24를 에이전트가 직접 조작해요 — 로그인·정보입력 자동" |
| 20–32s | 📱 **스마트폰**으로 전환 — 카카오톡 인증 알림 → [인증하기] 탭 (손가락 나오게) | "본인인증만 사용자가 — 명의도용 못 하게 일부러 사람이 하는 안전 설계" |
| 32–48s | 다시 PC — 발급 폼 자동 진행 → **신청하기 자동 클릭 → 문서출력** | "이후 신청·발급은 다시 자동으로" |
| 48–58s | **바탕화면\모두봄서류에 PDF가 생기는 순간** 클로즈업 → PDF 열어서 진짜 등본 보여주기 | "등본 발급 완료 — 8단계가 폰 승인 1번으로" |
| 58–60s | 로고 + "개인정보 서버 전송 0 · 목업 아님, 실제 정부24" | — |

## 핵심 메시지(심사·투표 어필)
- **"목업이 아니라 진짜 정부24를 조작한다"** — 이게 최대 차별점. 자막으로 강조.
- **"본인인증만 사람"** — 안전·정직 설계(완전 무인 대리인증 배제)를 반드시 언급(윤리 질문 방어).
- **"8단계 → 1단계"** — 사회적 임팩트(디지털 약자·시간빈곤층) 한 줄로.

## 촬영 팁
- 세로 대신 **가로(16:9)** — 발표 슬라이드/홈 양쪽에 쓰기 좋음.
- 개인정보(주민번호 뒷자리·실명)는 **블러/모자이크** 처리.
- 카카오 인증 화면의 개인정보도 가림.
