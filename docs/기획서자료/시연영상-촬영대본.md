# 시연 영상 촬영 대본 — 예선 투표용 (90초 풀 여정)

> 7/15 산출물 제출 게시글에 링크로 첨부. 투표자(참가자 전원+커뮤니티)가 가장 먼저 보는 자료라
> 영상 품질이 득표에 직결된다. 기존 60초 RPA 가이드(RPA-시연영상-가이드.md)의 발급 장면을
> 전체 서비스 여정 안에 배치한 확장판.

## 촬영 전 준비 (10분)

1. 백엔드 워밍: 라이브 사이트를 미리 한 번 열어 30초 대기(Render 콜드스타트 해소).
   챗봇에 아무 질문 하나 던져 AI 응답(보라색 AI 배지) 나오는 것까지 확인.
2. AI 의미 검색 프리워밍: 탐색 탭 → 'AI 의미 검색' 토글 켜고 모델 로딩 완료까지 대기(첫 로드 1~2분).
3. 브라우저: 크롬 시크릿 창(확장·북마크바 없는 깨끗한 화면), 창 최대화, 배율 100%.
4. 데스크탑 앱 리허설 1회(카카오 승인 흐름 확인), 바탕화면 `모두봄서류` 폴더 비우기.
5. 녹화: Win+G(게임바) 또는 OBS, 1080p 가로(16:9). 스마트폰 컷은 폰 화면 녹화 또는 손 포함 직접 촬영.
6. 개인정보: 실명·주민번호 뒷자리·전화번호는 편집에서 블러.

## 컷 순서 (총 ~90초)

| 시간 | 화면 | 하는 일 (클릭 단위) | 자막 |
|---|---|---|---|
| 0–6s | 홈 첫 화면 | 스크롤 없이 3D 새싹이+말풍선 잠깐 보여주기 | "복지, 몰라서 못 받는 사람이 더 많습니다" |
| 6–18s | 한 문장 분석 | 히어로 입력창에 음성 버튼 → **"72살인데 혼자 살고 소득이 적어요"** 말하기 → 분석 진행 화면 → 결과(TOP 추천+예상 금액) | "말 한마디면 AI가 받을 수 있는 복지를 찾아줘요" |
| 18–28s | 결과 활용 | 추천 카드 1개 상세 열기(신청 서류·기한) → [담아두기] → 챗봇 열어 **"서류는 뭐가 필요해?"** 질문 → 즉답 | "서류·기한·예상금액까지 한 번에" |
| 28–40s | 다국어(차별점) | 탐색 → AI 의미 검색에 **"tiền hỗ trợ sinh con"**(베트남어: 출산지원금) 입력 → 결과 + AI 답변 카드 | "외국인·다문화 가정도 — 자국어로 물으면 AI가 찾아줘요 (서버 전송 0, 브라우저 안에서)" |
| 40–62s | **자동발급(킬러)** | 데스크탑 앱에서 [등본 자동발급] → 정부24 자동 로그인·정보 자동입력 → **폰 컷: 카카오 인증 탭** → PC 복귀: 발급 자동 진행 → `모두봄서류` 폴더에 PDF 생기는 순간 클로즈업 | "서류는 AI가 정부24를 직접 조작해 발급 — 본인인증만 사람이 (안전 설계)" |
| 62–75s | 신청까지 | 나의 복지 → 담아둔 정책 [신청하기] → 복지로 신청 화면 자동 이동·정보 자동작성 → **제출 직전 멈춤** 강조 | "신청서 작성까지 자동, 최종 제출은 반드시 본인이 — 끝까지 정직하게" |
| 75–86s | 사후관리 | 나의 복지 대시보드: 갱신 임박 배지·서류 미비 알림·월 예상 수급액 합계 | "신청 후에도 갱신·기한을 계속 챙겨드려요" |
| 86–90s | 마무리 | 로고 + QR(라이브 URL) | "모두봄 — 목업 아님, 실제 정부24 · 지금 바로: biocode67.github.io/modoo-bom" |

## 선택 컷 — 📞 통화형 상담 변형 (7/19 신설 기능, 더 강한 서사가 필요할 때)

- **18–28s 대체안**: 챗봇 대신 챗 헤더 **📞**로 통화 화면을 열고 **"서류는 뭐가 필요해?"를 말로** →
  큰 글씨 자막 + 소리로 답이 나온다. 자막: *"전화 걸듯 말로만 — 화면을 못 읽어도 상담 완주"*.
  (통화에서 "72살 혼자 살고 소득이 적어요"를 말하면 그 자리에서 진단+음성 브리핑까지 — 6–18s와 합쳐
  한 씬으로 만들 수도 있다. 끊어도 대화가 챗에 남는 장면을 1초 보여주면 신뢰 +1.)
- **28–40s 변형(3초)**: 홈 외국인 섹션의 **📞 Tiếng Việt** 버튼 → 베트남어 인사로 통화가 시작되는 컷을
  AI 검색 앞에 끼우면 "자국어로 '전화'까지"가 된다. 참고 초안: `frontend/e2e/demo-video/modoobom-demo.webm`
  (record-demo.py가 통화 질문→답변→🇻🇳 전환 장면 포함해 자동 녹화).

## 반드시 지킬 것

- **40–62초 발급 장면이 승부처.** 여기서 "화면이 진짜 정부24"임이 보이게 주소창을 프레임에 포함.
- 실패 컷도 대비: 카카오 인증이 늦으면 폰 컷을 먼저 찍어두고 편집으로 잇기.
- 자막은 짧게(한 줄 12자 내외), 내레이션 없어도 이해되게.
- 마지막 QR은 3초 이상 고정(투표자가 폰으로 찍을 시간).

## 업로드·제출

- 유튜브 '일부공개(unlisted)'로 업로드 → DACON 산출물 게시글 본문 맨 위에 링크.
- 기획서 PDF 마지막 장에도 같은 QR/링크 삽입.

## 본선(8/11)용 개정 — 40~75초를 '🚀 원클릭 연쇄' 단일 씬으로

> 예선 대본은 발급(40–62s)과 신청(62–75s)이 **따로**였다. 이제 데스크탑앱의
> **[🚀 전부 자동발급 + 자동신청까지]** 가 있으므로, 본선 백업 영상은 이 구간을
> **버튼 한 번 → 발급 → 자동첨부 → 제출 직전 정지**의 한 호흡으로 다시 찍는 게 훨씬 강하다.

| 시간 | 화면 | 하는 일 | 자막 |
|---|---|---|---|
| 40–44s | 서류 도우미 | **[🚀 전부 자동발급 + 자동신청까지]** 클릭 → 진행률 바(0/2) 등장 | "버튼은 이게 마지막입니다" |
| 44–56s | 정부24 자동 진행 | 로그인·정보 자동입력 → **📱 알림음 순간** 폰 컷(카카오 [인증 허용] 탭) → 발급 PDF 저장, 진행률 1/2 | "인증만 사람이 — 알림음이 '폰 잡으세요' 신호예요" |
| 56–70s | 복지로 자동 진행 | 신청 페이지 자동 이동 → 양식 자동작성 → **방금 발급한 등본이 첨부칸에 자동으로 붙는 순간 클로즈업** → **제출 직전 정지** | "방금 뗀 서류가 그대로 첨부 — 제출 직전에 멈춥니다" |
| 70–75s | 종결 요약 | 앱 복귀: "✅ 연쇄 끝 — 서류 1건 발급 · 신청 양식 1건 준비" 배너 + [✓ 제출까지 마쳤어요] 클릭 → 사후관리 연결 | "여기까지 클릭 1번 + 폰 승인 1번" |

- **시간 제어**: 촬영 전 리허설로 가족관계·소득금액을 미리 발급(앱이 '발급 완료' 기억) → 본 촬영은
  등본 1종+신청만 연쇄돼 30초 안에 끝난다. 전부 실기능(발급 성공 자동 기억)이라 연출이 아니다.
- **막히면**: 진행률 바의 [⏭ 이 단계 건너뛰기]를 누르는 컷 자체가 '무정지 설계' 어필이 된다.
- 나머지 컷(0–40s 찾기·다국어, 75–90s 사후관리·QR)은 예선 대본 그대로.
