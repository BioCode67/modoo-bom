## 1. 개요

### 1.1 한 줄 정의
**나이·소득·상황(또는 어떤 언어로든 한 문장)만 알려주면, AI Agent가 전국 5,000여 개 복지·장학·지원금에서 내게 맞는 혜택을 찾아 정리해 주고, 사용자가 "신청하기"를 누르면 실제 정부 사이트에서 서류 발급·신청까지 자동으로 수행하는 개인 복지 AI Agent.**

### 1.2 문제 인식 — "복지는 아는 사람만 받는다"
- 대한민국 복지 제도는 중앙부처 460여 개 + 지자체 4,600여 개로 흩어져 있고, 담당 사이트도 정부24·복지로·고용24·한국장학재단 등으로 분산.
- 신청주의 원칙: **본인이 찾아서, 서류를 떼서, 신청해야** 받는다. → 정보 격차가 곧 소득 격차.
- 특히 사각지대: ①디지털 약자(어르신·장애인) ②**언어 장벽**(외국인·다문화 가정 — 한국어 검색 자체가 불가) ③시간 빈곤(일하며 아이 키우는 한부모 등).

### 1.3 해결 — 3단계를 하나의 Agent로
```
① 찾기: 프로필/자연어 한 문장(다국어·음성) → 온디바이스 AI가 5,185건에서 의미 매칭
② 정리: 자격 판정 + 예상 금액 + 필요 서류 + 신청처 → 신청 키트로 정돈
③ 실행: 크롬 확장이 사용자 브라우저 안에서 정부24 로그인→인증 자동입력→발급 폼→PDF 저장까지 자동
        (본인인증 폰 승인·최종 확인만 사용자 — 법적·비가역 행위 보호)
```

## 2. 주제 정합성 — "라이프스타일 혁신을 위한 AI Agent"

| 대회 키워드 | 모두봄의 구현 |
|---|---|
| **AI Agent** | ① 브라우저 안에서 직접 도는 신경망 임베딩 AI(온디바이스) ② LangGraph 10노드 에이전트(분석→검색→자격판정→반성 루프→가이드) ③ 실제 정부 사이트를 조작하는 RPA 실행기 ④ 생애주기 선제 알림(앞으로 열리고 닫히는 복지를 미리 챙김) |
| **라이프스타일 혁신** | "복지를 찾아다니는 삶 → 복지가 나를 찾아오는 삶". 정보 격차·언어 장벽·신청 장벽 3중 제거 |
| **SW 완성도** | 정적 배포로 즉시 체험, 실데이터 5,185건, 자동 테스트 219개(프론트 206+백엔드 13), 실제 정부 사이트 자동화 검증 |

## 3. 주요 기능

### 3.1 ⭐ 온디바이스 다국어 AI 의미검색 (헤드라인)
- **브라우저에서 직접 실행되는** 신경망 임베딩 모델(multilingual-e5-small, transformers.js)로 복지를 *의미*로 매칭 — 서버 전송 0, 회원가입 0.
- **다국어 교차검색**: "I lost my job and need money" → 긴급복지지원·국민취업지원. "Tôi là người khuyết tật"(베트남어) → 장애인연금. 한/영/베/중/일 검증.
- 자국어 **음성 대화**(말하면 음성으로 답), 입력 언어 자동 감지, 검색결과 기반 **AI 요약 답변**(환각 없음).
- 정책 벡터 5,185건은 빌드 시 사전계산 → 런타임은 질의만 임베딩(빠름). 모델 로딩 중엔 키워드 결과 먼저(끊김 없는 UX).

### 3.2 맞춤 분석 — "나에게 뭐가 되는데?"
- 프로필 위저드(나이·소득·가구·장애·자녀·생애이벤트) 또는 **자연어 한 문장 즉시 분석**(음성 포함).
- 2026년 공식 선정기준(생계32%·의료40%·주거48%·교육50%)으로 정밀 자격판정 + **예상 수령액 계산**.
- 기초생활보장 급여 계산기(가구원수→소득상한 게이지), 생애주기 시뮬레이터, 긴급복지 진단, 복지 점수·TOP3.

### 3.3 실행 자동화 — 크롬 확장 RPA (이번 프로토타입의 핵심 진전)
- **설치형 크롬 확장**이 사용자 브라우저 안에서 정부 사이트를 직접 자동화 — 서버·Python·로컬 설치 불필요, 개인정보는 브라우저 밖으로 나가지 않음.
- 자동 수행: 정부24 로그인 이동 → **간편인증(카카오) 선택** → 이름·생년월일·휴대폰·약관동의 **자동 입력** → 발급 폼 → **신청 제출** → **PDF 자동 저장**.
- 사용자 몫은 둘뿐: 📱 카카오 폰 승인(본인인증 — 법적 강제)과 발급 정보 최종 확인(5초 검토 후 자동 진행, 수정 개입 가능).
- 지원: 서류 13종(등본·초본·가족관계·장애인증명·소득금액증명·건보 자격득실·고용보험 이력 등) + 복지로·장학재단 신청 흐름(카탈로그 전 정책 딥링크 일반화).
- 기술 난제 해결(실사용 검증): 정부 버튼의 신뢰 클릭(isTrusted) 게이트 → **debugger 프로토콜 기반 '진짜 클릭'**, 안티매크로(Mbuster) 대응, MV3 서비스워커 생존성, 오버레이 가림 자동 회피, 단계별 자가진단 로그.

### 3.4 사후관리 — 신청하고 끝이 아니라
- '나의 복지'에서 관심·신청·수령 상태 관리, **모니터링 엔진**이 서류미비·진행점검·갱신임박을 산출해 알림.
- 지난 방문 이후 **새로 열린 복지를 선제 안내**(연속성 에이전트), 복지 캘린더(.ics), 신청기한 배지.

### 3.5 포용 설계 (접근성)
- 큰글씨·고대비 모드, 음성 입력/TTS 읽어주기, ESC/ARIA/focus-visible, PWA(설치·오프라인), 어려운 행정용어 → 쉬운 말 정비, 3D 마스코트로 심리적 문턱 낮춤.

## 4. 시스템 구성

### 4.1 아키텍처 (그림: diagram1-아키텍처.png)
```
[사용자 브라우저]
 ├─ 웹앱(React·정적 배포) ── 복지 엔진 + 온디바이스 AI(transformers.js) + PWA
 ├─ 크롬 확장(MV3) ──────── 정부24·복지로 등 실제 사이트 RPA(브라우저 내부)
 └─ (선택) 로컬 에이전트 ── FastAPI + LangGraph 10노드 + ChromaDB RAG + Playwright RPA
```
- **서버가 없어도 전 기능**: 탐색·AI 검색·분석·신청 키트는 정적 사이트 단독으로 동작(비용 $0, 항상 켜짐).
- 개인정보(이름·생년월일·휴대폰)는 **기기(localStorage)와 확장 내부에만** 존재 — 어떤 서버로도 전송하지 않음.

### 4.2 AI Agent 설계 (그림: diagram5-LangGraph10노드.png)
- LangGraph StateGraph 10노드: 프로필 분석 → RAG 검색 → 자격 판정 → **반성(reflection) 재판정 루프** → 가이드 생성 → 서류 취득 → 포트폴리오 → 알림 → 추적 → 오케스트레이터.
- LLM 무키 환경을 위한 **Mock 모드**(규칙 기반)로 데모 재현성 보장. LLM은 Anthropic Claude(교체는 env 한 곳).

### 4.3 데이터 (실데이터 원칙 — 그림: chart1-출처구성.png)
| 출처 | 건수 | 비고 |
|---|---|---|
| 보건복지부 등 검증 시드 | 124 | 정밀 자격판정·2026 검증 금액(출처표 별첨) |
| 중앙부처 공공데이터 | 463 | 한국사회장보정보원 OpenAPI |
| 지자체 공공데이터 | 4,598 | 시·군·구별 사업 |
| **합계** | **5,185** | 이름 디듑, **가짜 데이터 미생성** |

### 4.4 정직성·안전 설계 (심사 신뢰 포인트)
- 완전 무인 제출은 **설계상 배제**: 본인인증(폰 승인)과 최종 제출 확인은 반드시 사용자 — 명의도용·비가역 행위 방지(휴먼인더루프).
- 동작이 검증된 범위만 "된다"고 표기. 추적 불가한 것(정부 서버 실시간 상태)은 공식 조회 링크로 정직하게 안내.

## 5. 차별성 — 기존 서비스 대비

|---|---|---|
| 탐색 | 키워드 검색, 사이트별 분산 | **AI 의미검색**으로 통합(뜻을 이해) |
| 언어 | 한국어 중심 | **5개 언어+ 교차검색·음성**(한 화면) |

| 실행 | 사이트마다 직접 신청 | **브라우저 확장이 자동 수행**(인증만 본인) |
| 개인정보 | 서버 저장·로그인 | **온디바이스, 회원가입 불필요** |
| 사후관리 | 없음 | 모니터링·갱신임박·선제 안내 |

## 6. 개발 현황·품질 (프로토타입 3주차 기준)

- 자동 테스트 **219개 통과**(프론트 vitest 206 + 백엔드 pytest 13), ESLint 0건, TypeScript strict, 확장 자동 회귀 테스트(selftest) 별도 운영.
- 실사용 검증: 정부24 **주민등록등본 실제 발급 성공**(처리완료·PDF 저장), 6개 정부 사이트 간편인증 진입 자동화 검증.
- 성능: 초기 번들 영향 0(AI는 지연로드 별도 청크), Lighthouse 친화 정적 배포, PWA 오프라인.

## 7. 기대 효과
- **복지 사각지대 축소**: 몰라서 못 받던 혜택의 발견율 향상(특히 외국인·어르신).
- **신청 비용 절감**: 서류 발급 8단계 → 폰 승인 1단계.
- **공공 신뢰 모델**: 개인정보 무전송 구조는 공공 AI 서비스의 프라이버시 표준안이 될 수 있음.
- **확장성**: 카탈로그는 공공데이터 ETL로 자동 확장, 신청 자동화는 딥링크 일반화로 사이트 추가가 쉬움.

## 8. 향후 계획 (본선까지)
1. 크롬 웹스토어 정식 등록(패키징·심사 자료 완비) → 원클릭 설치.
2. 서류→신청 연쇄 자동화(신청에 필요한 서류를 먼저 자동 발급 후 신청 폼으로).
3. 다국어 UI 확대(현재 검색·음성 다국어 → 화면 전체).
4. 시연 시나리오 고도화: 외국인 유학생·독거 어르신·한부모 3종 페르소나 라이브 데모.
