# 예선 투표용 데모 영상 대본 — "정부24 서류, 폰 1탭으로"

> 리서치 결론 반영: **예선은 투표. 첫 40초 훅 + 썸네일 + 라이브 링크가 표를 가른다.**
> 원칙: ①기능 나열 금지, '당신'의 문제로 시작 ②우리만의 차별점(실제 발급·신청 자동화 + 다국어)을 하이라이트 ③에너지 > 완벽. 모든 수치는 라이브와 동일(실측·과장 0).
> 촬영: 전부 라이브(https://biocode67.github.io/modoo-bom/) 화면녹화 + 폰(카카오톡). 60초 본편 + 30초 숏컷 + 썸네일.

---

## 🖼️ 썸네일 (클릭률 = 노출 = 득표)
- 배경: 봄빛 그라데이션 + **웃는 새싹이**(og.png 캐릭터)
- 큰 글씨 2줄: **“정부24 서류,\n폰 1탭으로 자동 발급”**
- 하단 배지: `AI 복지 에이전트 · 모두봄` / `회원가입 없이 무료`
- 제목(영상): **“몰라서 못 받는 복지, AI가 신청·발급까지 대신 — 모두봄”**

## 🎬 본편 60초 (shot-by-shot)

**[0:00–0:08] 훅 — 당신의 문제** *(화면: 흩어진 정부 사이트들이 스쳐가다 → 새싹이 등장)*
> (내레이션·힘 있게) “당신이 받을 수 있는데, **몰라서 못 받는 복지.** 정부·지자체·민간재단에 **5천 건 넘게** 흩어져 있고, 말은 어렵고, 신청은 더 어렵습니다.”
> (자막) `자격이 있어도 — 몰라서, 어려워서 못 받는다`

**[0:08–0:20] 찾기 — 한 문장이면 끝** *(라이브: 홈 입력창)*
> ⌨️ **“72세 혼자 사는데 소득이 적어요”** 입력 → 결과.
> “회원가입도, 서버도 없습니다. **내 폰 안에서** AI가 5천 건에서 내 것만 찾아줍니다.”
> (자막) `핵심 현금지원 월 최대 63만 9천원 + 정부 어디에도 없는 민간재단 💝`

**[0:20–0:27] 다국어 — 사각지대까지** *(라이브: 외국어 예시 탭)*
> ⌨️ **“Tôi mất việc và không có tiền”**(베트남어) → 한국 복지 매칭.
> “한국어가 서툰 분도 **모국어로** 찾습니다. 번역 서버도 안 거칩니다 — 브라우저 안 AI니까요.”

**[0:27–0:47] ⭐신청·발급 — 여기가 다릅니다** *(라이브: 서류 자동발급 → 폰 클로즈업)*
> “다른 서비스는 여기서 **링크만** 줍니다. 모두봄은 **직접 갑니다.**”
> [자동발급] → 정부24 자동 진행 → 📱 **폰 들어 보이며** “본인인증만 제가 — 이건 법이 사람에게 요구하는 단 하나의 단계입니다” → 카카오 1탭 → 서류 발급 완료.
> (자막·비교) `서류 발급 8단계 → 폰 1탭` / `목업 아님 — 실제 정부24 그대로`

**[0:47–0:55] 신뢰 — 왜 믿어도 되나** *(화면: 숫자 카드)*
> “**약 5,300건 실데이터 · 테스트 751개 · 실브라우저 검증 · 환각 0 설계.**
> 과장을 **코드로** 막았습니다 — 심사형 지원을 ‘자격 있음’으로 표시하는 것조차 테스트가 거부합니다.”

**[0:55–1:00] CTA** *(화면: QR + URL + 새싹이)*
> “지금, 당신의 몰랐던 권리를 찾으세요. **모두봄.**”
> (자막) `지금 눌러보세요 → biocode67.github.io/modoo-bom`
