# 실측 자동화 확장 요약 (2026-07-20 새벽~아침, 본선 전 실사용 런)

실사용자(실제 본인인증) 리허설에서 나온 제보·스크린샷을 근거로 한 확장 기록.
전부 `main` 반영·CI 그린(deploy ~#244), pytest 282 · vitest 780. **날조 없음** — 모든 흐름은
사용자 스크린샷 실측 또는 실발급 완주로 검증되었고, 미검증 지점은 각 항목에 명시.

## 1) 정부24 간편인증 공통 (base.py / gov24_rpa.py)

- **동의 리셋 방지**: 카카오톡(제공자) 선택이 '전체동의'를 지우는 실측 확정 → 순서를
  '제공자 (재)선택 → 전체동의 마지막' 으로 강제. 로그인·전자서명 두 경로 동일.
- **선택 확정 게이트**: `click_provider_in_anyid` 가 `"trusted"|"js"|False` 반환 —
  자동 [인증 요청]은 trusted 일 때만("인증서비스를 선택하여 주십시오" 재발 방지).
- **[인증 완료] 자동 클릭**: 폰 승인 후 완료 버튼을 20초부터 12초 간격 자동 클릭
  (`wait_for_login`, 승인 전엔 '미완료' 안내만 닫고 재시도) — 복지로 로그인에도 그대로 적용.
- **점검/전자문서지갑 팝업**: '보이는 모달'만 검사(본문 보일러플레이트 오탐 방지),
  가족관계는 efamily 직행 안내·소득/납세는 홈택스 08~22시 안내(_direct_site_hint).
- **막힘 스마트 복구**: 진행 신호 없으면 예상 밖 팝업 [확인] 닫고 재시도 → 그래도 막히면
  사용자 수정 유예 후 자동 재신청(human-in-the-loop).

## 2) 🔒 개인정보 최소화 (사용자 요청)

- 등본류: 표시방식 **'전체표시'→'선택표시'** 자동 전환 + **주민등록번호 뒷자리 미포함/비공개**
  자동 선택(해당 행에서만 — 세대원 등 다른 항목 불가침). `RPA_PRIVACY_MASK=0` 밸브.
- 소득금액증명: 주민등록번호 공개여부 **'비공개'**(div 행 구조 대응). 주소·소득발생처는 제출용으로
  기본 '공개' 유지.
- 앱 폼: 주민번호 뒷 7자리·부/모 성명은 **password 마스킹(●) 입력** + 디스크/탭기억/서버 어디에도
  미보관(rpaInfoKeep FIELDS 제외 — vitest 계약).

## 3) 가족관계증명서 — 대법원 efamily 전자동 (실발급 완주 ✅)

상세: `docs/가족관계증명서-efamily-실측.md`. 정부24 연계는 전자문서지갑 선행+차단으로 실사용 불가
확정 → 원 발급처 직행. 폰 [인증 허용] 한 번 외 전 단계 자동, 주민번호 '전부 비공개' 발급,
**원본 PDF 직다운로드**(뷰어 재인쇄 잘림 해소).

## 4) 소득금액증명 — 신청서 자동 채움 (실측 스크린샷)

- 증명받는 기간(시작·종료년도) = 직전 과세연도 자동 입력.
- 용도: [검색] → '코드정보 조회' 팝업(새 창)에서 **'관공서제출용'** 자동 선택.
- ⚠️ 운영 제약: 홈택스 08~22시. **신고 소득이 없는 해는 국세청이 '취소' 처리**(앱 오류 아님) —
  무소득자는 홈택스 '사실증명(신고사실없음)'이 정석. (미검증: 용도 팝업 실클릭 — 실PC 확인 필요)

## 5) 복지로 자동신청 — '서비스 선택' 화면 브리지 (apply_rpa 최소 추가 · 팀원 확인 요망)

실측: 로그인 후 '복지급여 신청 — 서비스 선택' 그리드(selectServChs)에서 수동 개입이 필요했음 →
`_pass_service_select_page` 추가형 브리지: 화면 시그니처('저장 후 다음단계')가 있을 때만
서비스 카드 체크(공백무시 매칭) → [저장 후 다음단계] → 확인 다이얼로그 [확인] 자동.
시그니처 없으면 no-op(골든패스 무영향 계약 검증). **최종 제출은 여전히 본인**(제출 직전 정지 불변).
(미검증: 실PC 브리지 실행 — 데모 영상은 확인창 직전까지로 확정)

## 6) 기타

- 나의 복지: 담은 혜택 필요서류만 표시(15종 그리드 자동펼침 제거), 카드에 📮 공식 신청 링크
  (고용24 등 비자동 혜택), 옥천군 등 '빈 지자체 스텁'이 국가 시드를 가리던 카탈로그 결함 수정.
- run-local-app.bat 서버 미기동 버그(pushd 후 상대경로) 수정, 브라우저 자동오픈 견고화(60초·127.0.0.1·
  최후 폴백), update-and-publish.bat 원클릭(pull→빌드→게시) 신설.
- ⚠️ **배포본(exe) 반영은 `update-and-publish.bat` 실행 시점** — 소스 실행(run-local-app)은 즉시 반영.
