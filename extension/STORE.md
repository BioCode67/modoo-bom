# 크롬 웹스토어 등록 안내 (STORE)

> 이 문서는 크롬 웹스토어 개발자 대시보드에 제출할 때 그대로 붙여 넣을 메타데이터와,
> 심사 통과를 위한 권한/개인정보 소명을 담습니다. 제출용 zip 은 `build.ps1` 로 생성합니다.

## 제출 절차
1. `powershell -ExecutionPolicy Bypass -File extension\build.ps1` → `extension\dist\modoo-agent-<version>.zip`
2. https://chrome.google.com/webstore/devconsole 접속(최초 1회 개발자 등록비 $5)
3. **새 항목** → zip 업로드 → 아래 메타데이터 입력 → 스크린샷 첨부 → 제출(심사 수일)

- **이름**: 모두봄 복지 에이전트

- **카테고리**: 생산성(Productivity)
- **언어**: 한국어
- **상세 설명**:
  ```
  모두봄 복지 에이전트는 복잡한 복지 신청을 대신 해주는 브라우저 도우미입니다.
  - 서류 자동발급 13종: 정부24(등본·초본·가족관계·장애인증명·소득금액증명·지방세 납세/과세·

    (+ 카탈로그의 복지로 딥링크 정책 전체) · 한국장학재단 장학금 신청

  사용자가 직접 합니다(비가역 행위 안전장치).

  전송·저장되지 않습니다. 발급 문서도 사용자 기기에만 저장됩니다.
  ```

## 권한 소명 (심사 필수)
- `scripting`, `tabs`: 발급/신청 진행을 위해 정부24·복지로 탭을 열고 자동화 스크립트를 주입합니다.
- `storage`: 진행 상태 표시·문제 진단 기록용(개인정보 저장 아님).
- `debugger`: 두 가지 용도로만 사용합니다. ①발급 완료 문서를 PDF로 저장(Page.printToPDF)
  ②정부 사이트의 일부 버튼이 보안상 실제 사용자 클릭(isTrusted)만 허용하므로, 사용자가 시작한
  발급 작업의 해당 탭에 한해 신뢰 클릭(Input.dispatchMouseEvent)을 전달. 사용자가 시작한
  작업 탭 외에는 절대 attach하지 않으며, 데이터 수집·감청 용도로 사용하지 않습니다.
- `downloads`: 발급된 PDF를 사용자 다운로드 폴더에 저장.
- `alarms`: 발급 작업 진행 중 MV3 서비스워커가 유휴 종료되어도 연쇄 발급 큐가 멈추지 않도록
  복구용 1회성 알람을 설정(50초 안전망). 주기적 백그라운드 작업·추적 용도가 아님.
- host_permissions(`plus.gov.kr`, `www.gov.kr`, `*.gov.kr`, `www.bokjiro.go.kr`, `*.yeskey.or.kr`,
  `www.nhis.or.kr`, `www.work24.go.kr`, `www.nps.or.kr`, `minwon.nps.or.kr`, `www.kosaf.go.kr`):
  해당 정부·공공 사이트에서만 발급/신청 자동화를 수행하기 위함. 그 외 사이트에서는 동작하지 않습니다.
- 원격 코드 사용 없음. 모든 로직은 확장 패키지 내부에 포함.

## 개인정보처리방침 (필수 URL)
크롬 웹스토어는 개인정보 처리 확장에 개인정보처리방침 URL을 요구합니다.
프로젝트의 공개 방침(예: https://biocode67.github.io/modoo-bom/privacy.html)을 등록하세요.
핵심 문구: "본 확장은 사용자 개인정보를 외부 서버로 전송하거나 저장하지 않습니다. 입력 정보는
정부 사이트 자동입력 목적에 한해 사용자의 브라우저 내에서만 처리됩니다."
