# 모두봄 복지 에이전트 (크롬 확장)

배포된 모두봄 웹(https://biocode67.github.io/modoo-bom/)에서 **로컬 서버 설치 없이**
정부24 서류 자동발급을 **사용자 브라우저 안에서** 실행하는 크롬 확장입니다.

## 왜 확장인가
순수 웹페이지는 브라우저 동일출처 정책 때문에 정부24 같은 다른 사이트를 조작할 수 없습니다.
확장은 사용자 브라우저 안에서 동작하므로:
- ✅ 설치가 "크롬에 추가" 한 번(파이썬/로컬서버 불필요)
- ✅ **본인인증이 진짜 됨**(사용자 자기 브라우저·세션·폰)
- ✅ 개인정보가 브라우저 밖으로 안 나감(서버 경유 0)
- ✅ 정부 사이트가 사용자 실제 브라우저·가정 IP로 인식 → 봇/IP 차단 없음

## 설치 (개발자 모드 / 데모)
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 `extension/` 폴더 선택
4. 모두봄 웹을 새로고침하면 '서류 준비 도우미'에 **자동발급** 버튼이 활성화됩니다.

> 정식 배포 시에는 Chrome 웹스토어에 등록하면 사용자는 "Chrome에 추가" 한 번으로 설치합니다.

## 지원 범위
- **서류 자동발급**:
  - 정부24 — 주민등록등본·초본, 가족관계증명서, 장애인증명서, 소득금액증명, 지방세 납세증명서,
    지방세 세목별 과세증명서, **국민기초생활수급자 증명서, 한부모가족 증명서**(복지 신청 핵심)
  - 건강보험공단 — 건강보험 자격득실확인서
  - 고용24 — 고용보험 피보험자격 이력내역서
  - 국민연금공단 — 국민연금 가입자 증명서(정부24 경로)·가입내역확인서(nps 직접)
- **복지 자동신청**:
  - 복지로 — 카탈로그의 **모든 복지 정책**(실제 `wlfareInfoId` 딥링크, 수백 개). 프론트가 각 정책의 실제 신청 URL을 확장에 전달.
  - 한국장학재단 — 국가장학금 등 장학금 신청(kosaf.go.kr, 신청 URL로 라우팅).
  (로그인·서비스 이동·양식 작성까지 자동, 본인인증·최종 제출은 사용자 직접)

## 동작 흐름
1. 웹에서 [자동] 클릭 → 확장이 새 탭에 정부24(plus.gov.kr) 로그인 페이지를 엽니다.
2. 간편인증을 자동 선택하고, 카카오톡 선택 + 이름/생년월일/휴대폰 + 전체동의를 자동 입력합니다.
3. 🔐 **사용자가 '인증 요청' 클릭 + 📱 카카오톡 [인증 허용]** (본인인증은 반드시 본인).
4. 로그인 후 발급 폼으로 자동 이동 → 양식 처리 → 신청 제출 → 출력/PDF 저장까지 진행.
5. 진행상황은 웹 카드와 확장 팝업에 표시됩니다.

### 🚀 연쇄 자동발급 (ISSUE_MANY)
- '서류 준비 도우미'의 **[필요한 서류 N종 전부 자동발급]** 버튼 → 한 번 로그인(정부24 세션 유지)으로
  담은 복지에 필요한 서류를 **순서대로 자동 발급**합니다(정부24 서류를 앞으로 정렬해 연쇄 최대화).

### '진짜 클릭'(신뢰 클릭) — 기술 메모
정부24의 일부 버튼(로그인 방식 카드·회원 신청하기·신청하기)은 보안상 **실제 사용자 클릭(isTrusted)만**
받아 프로그램 `.click()`을 무시합니다. 확장은 `chrome.debugger`의 `Input.dispatchMouseEvent`로 진짜
클릭을 만들어 이를 돌파합니다. 이때 상단에 "…이(가) 디버깅하고 있습니다" 배너가 잠깐 뜨는 건 정상입니다.

## 문제가 생기면 — 진단 복사
확장 팝업 하단 **[🔍 진단 복사]** 버튼을 누르면 자동화가 밟은 단계 기록(개인정보 미포함)이 클립보드에
복사됩니다. 이걸 개발자에게 붙여넣으면 어디서 멈췄는지 바로 특정할 수 있습니다.
- ⚠️ **개발자도구(F12)는 닫아 주세요** — 열려 있으면 확장이 debugger를 붙이지 못해 '진짜 클릭'이 실패합니다.
- 멈춘 작업은 팝업의 **[⛔ 작업 취소]**로 정리할 수 있습니다.

## 개인정보
- 이름·생년월일·휴대폰 등은 확장(브라우저) 내부에서만 사용되고 **서버로 전송되지 않습니다.**
- 발급 문서는 사용자 브라우저에서 인쇄/저장합니다.

## 구조
- `manifest.json` — MV3. 정부24 host_permissions + 웹앱 externally_connectable/bridge.
- `bridge.js` — 모두봄 웹 ↔ 확장 메시지 릴레이(확장 ID 불필요).
- `background.js` — 잡 상태머신, 탭 열기, 내비게이션마다 자동화 주입, 상태 릴레이.
- `automation.js` — 정부24 발급 흐름(간편인증→발급폼→출력) 자동화. 모든 프레임에 주입.
- `popup.html/js` — 진행상태 표시.

## 자동 회귀 테스트

### selftest.mjs (Node — 파이썬 불필요, 권장)
확장을 실 Chromium(playwright-core 번들)에 로드해 로그인 전 구간을 자동 검증합니다.
```bash
# playwright-core 준비: npm i -g playwright-core 또는 로컬 설치 후 PW_PATH 지정
node extension/selftest.mjs        # PING/13종, ISSUE 잡탭, AA020→발급폼, findEasy·realClick, ISSUE_MANY → 9/9
```
> 브랜드 크롬(채널 chrome)은 137+에서 `--load-extension`을 제거해 번들 chromium을 씁니다(스크립트가 자동 처리).
> 로그인 이후는 정부24 Mbuster 안티매크로가 자동화 브라우저를 차단해 재현 불가 — **실사용 크롬만** 검증 가능.

### validate_live.py (파이썬 환경이 있을 때)
```bash
cd backend && venv\Scripts\activate
python ../extension/validate_live.py "주민등록등본"                      # 정부24
python ../extension/validate_live.py "기초연금" apply                    # 복지로 신청
```
2026-07 기준 6개 사이트 모두 **간편인증 클릭 도달 ✅** (정부24는 Mbuster 보안페이지 대기 포함).
