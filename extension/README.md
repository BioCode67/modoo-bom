# 모두봄 복지 에이전트 (크롬 확장)

배포된 모두봄 웹(https://biocode67.github.io/modoo-bom/)에서 **로컬 서버 설치 없이**
정부24 서류 자동발급을 **사용자 브라우저 안에서** 실행하는 크롬 확장입니다.

## 왜 확장인가
순수 웹페이지는 브라우저 동일출처 정책 때문에 정부24 같은 다른 사이트를 조작할 수 없습니다.
확장은 사용자 브라우저 안에서 동작하므로:
- ✅ 설치가 "크롬에 추가" 한 번(파이썬/로컬서버 불필요)
- ✅ **본인인증이 진짜 됨**(사용자 자기 브라우저·세션·폰)
- ✅ 개인정보가 브라우저 밖으로 안 나감(서버 경유 0)
- ✅ 정부 사이트가 사용자 실제 브라우저·가정 IP로 인식 → 봇/IP 차단 없음

## 설치 (개발자 모드 / 데모)
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 `extension/` 폴더 선택
4. 모두봄 웹을 새로고침하면 '서류 준비 도우미'에 **자동발급** 버튼이 활성화됩니다.

> 정식 배포 시에는 Chrome 웹스토어에 등록하면 사용자는 "Chrome에 추가" 한 번으로 설치합니다.

## 지원 서류 (MVP)
정부24: 주민등록등본·초본, 가족관계증명서, 장애인증명서

## 동작 흐름
1. 웹에서 [자동] 클릭 → 확장이 새 탭에 정부24(plus.gov.kr) 로그인 페이지를 엽니다.
2. 간편인증을 자동 선택하고, 카카오톡 선택 + 이름/생년월일/휴대폰을 자동 입력합니다.
3. 🔐 **사용자가 '인증 요청' 클릭 + 📱 카카오톡 [인증 허용]** (본인인증은 반드시 본인).
4. 로그인 후 발급 폼으로 자동 이동 → 양식 처리 → 출력/저장 화면까지 진행.
5. 진행상황은 웹 카드와 확장 팝업에 표시됩니다.

## 개인정보
- 이름·생년월일·휴대폰 등은 확장(브라우저) 내부에서만 사용되고 **서버로 전송되지 않습니다.**
- 발급 문서는 사용자 브라우저에서 인쇄/저장합니다.

## 구조
- `manifest.json` — MV3. 정부24 host_permissions + 웹앱 externally_connectable/bridge.
- `bridge.js` — 모두봄 웹 ↔ 확장 메시지 릴레이(확장 ID 불필요).
- `background.js` — 잡 상태머신, 탭 열기, 내비게이션마다 자동화 주입, 상태 릴레이.
- `automation.js` — 정부24 발급 흐름(간편인증→발급폼→출력) 자동화. 모든 프레임에 주입.
- `popup.html/js` — 진행상태 표시.
