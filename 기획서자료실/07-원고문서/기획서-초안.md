## 1. 작품 개요 (한 문단)

**모두봄**은 "몰라서 못 받는 복지"를 없애는 **AI Agent 기반 개인 복지 비서**다. 프로필 또는 자연어 한 문장("72세 혼자 사는데 소득이 적어요")만으로 정부·지자체·민간재단에 흩어진 **5,200여 건**의 복지에서 내 것을 찾아주고, 어려운 행정용어를 쉬운 말로 풀어주며, 서류 발급과 신청까지 브라우저 안에서 **대신 실행**하고, 마감·갱신을 계속 지켜본다. 개인정보는 서버로 보내지 않는다(온디바이스 AI).

- 라이브: https://biocode67.github.io/modoo-bom/ (설치형 PWA, 로그인 불필요)
- 저장소: https://github.com/BioCode67/modoo-bom

## 2. 문제 정의 — 복지 사각지대는 '정보와 실행'의 문제

1. **흩어짐**: 중앙부처·지자체·민간재단이 각자 공고 — 한 곳에서 못 본다(특히 민간재단은 어떤 정부 포털에도 없음).
2. **어려움**: '기준 중위소득', '소득인정액' — 가장 필요한 사람(어르신·저소득·외국인)이 가장 못 읽는다.
3. **번거로움**: 자격이 있어도 서류 발급·신청 과정에서 포기한다.
4. 결과: 신청주의 복지의 구조적 미수급 — **자격이 있어도 몰라서, 어려워서 못 받는다.**

## 3. 솔루션 — 인지→판단→행동→관찰의 AI Agent 루프

| 단계 | 기능 | 기술 |
|---|---|---|
| **인지** | 1분 프로필 위저드 · 자연어 한 문장 분석 · 음성 입력 | 규칙 NLU(환각 0) |
| **판단** | 5,206건에서 자격판정(2026 정밀 선정기준) + 민간재단 연계 | 클라이언트 엔진 + 저신뢰 분리(정직) |
| **이해** | 쉬운 말 결과 · 용어사전 · **7개 언어 AI 답변**(en·vi·zh·ja·th·ru·ar) · TTS | **온디바이스 신경망**(multilingual-e5, 브라우저 실행) |
| **행동** | 챗에 "다 담아줘"→저장, "서류 뭐 필요해"→서류 요약 · **정부24 서류 13종 자동발급·복지로 자동신청**(크롬 확장) | 하이브리드 챗(LLM=Claude/규칙 폴백) + CDP 신뢰클릭 RPA |
| **관찰** | 마감 D-day·갱신·서류미비 감시, 열면 먼저 브리핑 | 온디바이스 모니터링 |

**안전장치(핵심 철학)**: 본인인증·최종 제출은 사람이 직접(human-in-the-loop). 무인 대행은 설계상 배제 — 법적으로도, 윤리적으로도 그것이 옳다.

## 5. 기대 효과 (실측 기반, '월 최대·중복 미반영' 명시)

- 독거 어르신(중위 25%): 핵심 현금지원 **월 최대 639,700원** 발견
- 출산 가정(0세): **월 최대 1,193,000원** + 60일 소급 시한 알림(놓치면 소급 소멸)
- 중증장애인: **월 최대 349,700원** + 민간 의료·재활 연계
- 외국인·다문화: 모국어로 묻고 모국어로 답 받는 유일한 복지 탐색 경험

## 7. 기술 구성

```
[React18+Vite PWA] ── 온디바이스: 복지엔진·의미검색(e5-small)·모니터링  ← 개인정보 이탈 0
      │ (감지 시)
[FastAPI + LangGraph 10노드 + Claude] ── 지식형 챗 LLM·RAG (규칙 폴백 내장)
      │
[크롬 확장(MV3)] ── 정부24·복지로·건보·고용24·국민연금·장학재단 RPA (CDP 신뢰클릭, 브라우저 內 실행)
```
