# 플레이스토어 등록 텍스트 (복사해서 사용)

## 앱 이름 (30자 이내)
모두봄 — 내 복지 혜택 찾기

## 간단한 설명 (80자 이내)
나이·상황만 알려주면 AI가 전국 5,000여 복지에서 내 혜택을 찾아 신청까지 안내해요

## 자세한 설명 (4000자 이내)

🌱 몰라서 못 받는 복지, 이제 모두봄이 대신 찾아드려요.

복지는 흩어져 있고, 용어는 어렵고, 신청은 복잡합니다.
모두봄은 나이·소득·가구 상황만 알려주면(또는 한 문장만 말하면)
전국 5,000여 건의 실제 복지 데이터에서 나에게 맞는 혜택을 골라
예상 금액·필요 서류·신청 방법까지 한 번에 안내하는 개인 복지 AI 도우미입니다.

■ 이런 분께 필요해요
• "받을 수 있는 게 있는지조차 모르겠어요" — 기초연금, 생계급여, 청년 지원…
• 부모님·어르신 복지를 대신 챙겨드리고 싶은 가족
• 한국어가 서툰 외국인·다문화 가정 (7개 언어로 물어보세요)
• 아이 키우며 받을 수 있는 수당을 놓치고 싶지 않은 부모님

■ 주요 기능
✔ 맞춤 복지 찾기 — 1분 프로필 입력 또는 "72세 혼자 사는데 소득이 적어요" 한마디면 끝
✔ AI 의미 검색 — 검색어가 아니라 '뜻'으로 찾아요. 한국어·English·Tiếng Việt 등 다국어 지원
✔ 예상 금액 계산 — 2026년 공식 기준으로 얼마나 받을 수 있는지 바로 확인
✔ 신청 도우미 — 필요한 서류 체크리스트 + 내 정보 자동 복사 + 공식 신청 페이지 바로 연결
✔ 나의 복지 관리 — 관심 복지 저장, 신청 진행 상황, 갱신 시기 알림
✔ 음성 대화 — 말로 묻고 음성으로 들으세요 (큰글씨·고대비 지원)

■ 개인정보 걱정 없어요
• 회원가입 없이 모든 핵심 기능 사용
• 입력한 정보는 내 폰 안에만 저장 — 서버로 전송하지 않아요
• AI도 내 기기 안에서 직접 실행 (온디바이스 AI)
• 광고 없음, 추적 없음

■ 정직한 안내
• 모든 정책 데이터는 정부 공공데이터와 공식 사이트 검증 자료입니다 (가짜 없음)
• 본인인증과 최종 제출은 정부 공식 사이트에서 직접 진행됩니다 (안전을 위한 설계)
• 심사·선발형 지원은 '가능성'으로만 표시하고 과장하지 않습니다

지금 내 복지를 확인해 보세요. 몰라서 놓친 권리를 모두봄이 찾아드립니다. 🌱
