# 모두봄 — 구글 플레이스토어 / 애플 앱스토어 출시 가이드

> 이 폴더에 **업로드만 하면 되는 완성 앱 파일**이 이미 만들어져 있습니다.
> 남은 것은 개발자 계정 가입(본인 명의·결제 필요라 직접 하셔야 함)과 콘솔에서의 업로드입니다.

---

## 0. 지금 완성돼 있는 것

| 파일 | 용도 |
|------|------|
| `modoobom-release.aab` | **플레이스토어 업로드용** 앱 번들 (서명 완료) |
| `modoobom-release.apk` | **내 폰에 직접 설치**해 보는 테스트용 (서명 완료) |
| `keystore/` | 앱 서명키 + 비밀번호(`KEYSTORE-INFO.txt`) — **커밋 제외됨. 지금 백업하세요** |
| `store-assets/` | 스토어 등록 그래픽: 특성그래픽 1024×500 + 폰 스크린샷 4장 |
| `twa-manifest.json` | 앱 정의(이름·색·아이콘·버전). 수정 후 `build.bat`로 재빌드 |
| `build.bat` | 원클릭 재빌드(빌드+서명+검증) |

**기술 방식**: TWA(Trusted Web Activity) — 배포된 PWA(biocode67.github.io/modoo-bom)를
크롬 엔진으로 전체화면 실행하는 **진짜 안드로이드 앱**. 웹을 재배포하면 앱도 자동으로 최신
(스토어 재심사 불필요 — 앱 껍데기가 아니라 웹이 콘텐츠라서).

**도메인 검증(assetlinks)**: `https://biocode67.github.io/.well-known/assetlinks.json` 에
서명키 지문이 배포되어 있어 앱에서 **주소창 없이** 열립니다. (이걸 위해 루트 저장소
`BioCode67/biocode67.github.io`를 새로 만들었습니다 — 삭제하면 앱에 주소창이 생기니 유지하세요.)

## 1. 먼저: 내 폰에서 테스트 (5분, 계정 불필요)

1. `modoobom-release.apk`를 폰으로 전송(카톡 나에게 보내기·USB·구글드라이브 등)
2. 폰에서 APK 열기 → "출처를 알 수 없는 앱" 허용 → 설치
3. 홈 화면의 🌱 모두봄 아이콘 실행 → **주소창 없는 전체화면**으로 뜨는지 확인

## 2. 구글 플레이스토어 (권장 — Windows에서 전 과정 가능)

### 2-1. 개발자 계정 (1회, $25)
1. https://play.google.com/console 접속 → Google 계정으로 가입
2. 등록비 **$25(1회)** 결제, 본인 확인(신분증) — 심사 1~2일
   - 개인 계정이면 충분. 2024년 이후 신규 **개인 계정은 프로덕션 공개 전
     "비공개 테스트 12명×14일" 요건**이 있습니다 → 학교 친구들로 채우면 됩니다.
     (대회 시연은 APK 직접 설치로 충분하니 병행 진행 추천)

### 2-2. 앱 만들기 + AAB 업로드
1. 콘솔 → **앱 만들기**: 이름 `모두봄 — 내 복지 혜택 찾기`, 기본 언어 한국어, 앱, 무료
2. **테스트 및 출시 → 비공개 테스트**(또는 내부 테스트) → 새 버전 만들기
3. **Google Play 앱 서명: "계속"(기본값 사용)** ← 권장. 우리 키는 업로드 키가 되어 분실해도 복구 가능
4. `modoobom-release.aab` 업로드 → 버전명 1.0.0 확인 → 저장

### 2-3. 스토어 등록정보 (아래 복붙)
- **앱 이름**: 모두봄 — 내 복지 혜택 찾기
- **간단한 설명(80자)**:
  `나이·상황만 알려주면 AI가 전국 5,000여 복지에서 내 혜택을 찾아 신청까지 안내해요`
- **자세한 설명**: `store-assets/스토어-설명문.md` 내용 복붙
- **그래픽**:
  - 앱 아이콘 512×512: `frontend/public/pwa-512x512.png`
  - 특성 그래픽 1024×500: `store-assets/feature-graphic.png`
  - 휴대전화 스크린샷(2장 이상): `store-assets/screenshot-1~4.png`
- **카테고리**: 소셜/커뮤니케이션보다는 **라이프스타일** 권장 · 태그: 복지, 정부 혜택
- **개인정보처리방침 URL**: `https://biocode67.github.io/modoo-bom/privacy.html`

### 2-4. 콘텐츠 설문 (정직하게 아래대로)
- **데이터 보안(Data safety)**:
  - "데이터를 수집하나요?" → **아니요**가 기본 (모든 입력은 기기 안 localStorage,
    서버 전송 0 — 우리 설계 그대로)
  - 단, 앱 안에서 **선택 로그인(카카오/구글, Supabase)** 을 쓸 수 있으므로 정확히 하려면:
    "수집함 → 개인 정보 > 이메일 주소 → 선택사항 → 계정 관리 목적 → 전송 중 암호화 → 삭제 요청 가능" 1건만 신고
- **콘텐츠 등급 설문**: 폭력·사행성 등 전부 "아니요" → 전체이용가
- **타겟층**: 만 18세 이상 권장(복지 신청 = 성인 행정 업무)
- **광고 포함 여부**: 없음

### 2-5. 심사 제출
모든 섹션 체크 완료 → **검토를 위해 제출**. 보통 수일 내 승인.
이후 웹(`npm run deploy`)만 재배포해도 앱 콘텐츠는 자동 최신화됩니다.

### 앱 업데이트(버전 올리기)가 필요한 경우
앱 껍데기 자체(이름·아이콘·색)를 바꿀 때만 필요:
1. `twa-manifest.json`: `appVersionCode` +1, `appVersionName` 수정
2. `app/build.gradle`의 `versionCode`/`versionName`도 동일하게
3. `build.bat` 더블클릭 → 새 AAB를 콘솔에 업로드

## 3. 애플 앱스토어 (솔직한 안내)

**Windows만으로는 불가능**합니다. 필요한 것:
- **Mac**(Xcode 필수 — 학교 실습실 Mac도 가능) 또는 클라우드 Mac(MacinCloud 등)
- **Apple Developer Program $99/년**
- 심사 기준상 "웹사이트 래핑 앱"은 반려될 수 있어(가이드라인 4.2 '최소 기능'),
  PWA 기능(오프라인·알림·온디바이스 AI)이 네이티브 가치임을 심사 노트에 설명해야 함

경로(택1):
1. **PWABuilder** (권장·무료): https://www.pwabuilder.com 에
   `https://biocode67.github.io/modoo-bom/` 입력 → iOS 패키지 다운로드 → Mac의 Xcode로 열어
   서명·업로드 (30분 수준)
2. **Capacitor**: 웹뷰 래핑 프로젝트 생성 후 Xcode 빌드 (더 유연, 손이 더 감)

> 현실적 추천: **플레이스토어 먼저 출시**하고, 아이폰 사용자는 사파리 "홈 화면에 추가"
> (PWA 설치)로 안내. iOS 스토어는 Mac 확보 후 진행.

## 4. 자주 묻는 것

- **Q. 앱에 주소창이 보여요** → assetlinks 반영 전 설치본. 앱 재설치 + 
  `https://biocode67.github.io/.well-known/assetlinks.json` 이 200인지 확인.
- **Q. keystore를 잃어버렸어요** → Play 앱 서명(기본값)을 켰다면 콘솔에서 업로드 키 재설정 요청 가능.
  안 켰다면 새 앱으로 재출시해야 하므로 **반드시 기본값 사용 + 백업**.
- **Q. 웹을 고치면 앱도 다시 심사받나요?** → 아니요. 웹 재배포만 하면 앱은 그대로 최신 콘텐츠.
- **Q. RPA 자동발급도 앱에서 되나요?** → 앱(=웹과 동일)은 무설치 3단계 경로로 동작.
  PC 로컬 에이전트 연동 기능은 PC에서만(설계상 의도).
