# 모두봄 로컬 에이전트 (진짜 크롬 + CDP) — 정부24 서류 자동발급

> 배포 웹의 크롬 확장이 **정부24 Mbuster 안티매크로**와 **debugger 좌표 클릭 불안정** 때문에
> 막히던 문제를 근본적으로 해결한 방식입니다.

## 왜 이 방식인가 (핵심)

| | Playwright 번들 크로미움 | 크롬 확장(debugger) | **진짜 크롬 + CDP (이 방식)** |
|---|---|---|---|
| 정부24 Mbuster | ❌ 차단 | ✅ 통과 | ✅ **통과**(navigator.webdriver=false) |
| 클릭 안정성 | ✅ 신뢰 클릭 | ⚠️ 좌표·가림 불안정 | ✅ **Playwright 신뢰 클릭** |
| iframe 인증창 | ✅ 프레임 API | ⚠️ 접근 까다로움 | ✅ **프레임 API로 정확** |
| 개발자 검증 | 로그인 벽까지만 | 불가(실크롬만) | ✅ **로그인 벽까지 자동 테스트 가능** |

즉, **사용자의 실제 크롬을 원격 디버깅으로 띄우고 Playwright가 CDP로 붙어** 조종합니다.
실제 크롬이라 Mbuster를 통과하고, Playwright라서 클릭·입력·프레임이 안정적입니다.

## 검증된 것 (실측)

로그인 → **Mbuster 통과** → 간편인증 선택 → `simpleCert.html` iframe →
이름(`#oacx_name`)·생년월일(`#oacx_birth`)·휴대폰 뒤8자리(`#oacx_phone2`)·전체동의(`#totalAgree`)
**자동 입력**까지 실제 크롬으로 검증 완료. 사용자는 **'인증 요청' + 📱 카카오 승인**만 하면
이후 발급 폼·신청·문서출력·PDF 저장을 에이전트가 이어서 수행합니다.

> 본인인증(카카오 폰 승인)과 최종 제출은 설계상 항상 사람이 — 명의도용·비가역 방지.

## 사용법

1. **`run-agent-cdp.bat` 더블클릭** (프로젝트 루트).
   - 자동화용 크롬 창이 열리고(전용 프로필), 파이썬 에이전트가 붙습니다.
2. 처음 한 번, 콘솔에 **이름·생년월일(8자리)·휴대폰(11자리)** 입력 →
   `backend/agent_profile.json`에 저장(이 PC에만, 서버 전송 없음).
3. 크롬 창에서 자동으로 로그인→간편인증→정보입력까지 진행됩니다.
4. **'인증 요청'을 누르고 📱 카카오톡에서 인증**을 완료하세요.
5. 이후 발급 폼→신청→문서출력→**PDF 자동 저장**(`바탕화면\모두봄서류`)까지 자동.

다른 서류·여러 서류: `run-agent-cdp.bat "주민등록등본" "가족관계증명서" "소득금액증명"` 처럼
여러 개를 넘기면 **한 번의 로그인(카카오 승인 1회)으로 연달아 발급**합니다.

지원 서류(정부24, AA040 발급폼 실측 확인 8종): 주민등록등본·초본, 장애인증명서, 소득금액증명,
지방세 납세증명서, 지방세 세목별 과세증명서, 기초생활수급자 증명서, 한부모가족 증명서.
(가족관계증명서·국민연금 가입자 증명서는 정부24 발급 흐름이 달라 제외 — 정직성 원칙.)

## 구조

- `backend/local_agent.py` — CDP 연결 + 정부24 흐름(로그인·인증 자동입력·발급·PDF).
- `run-agent-cdp.bat` — 진짜 크롬(원격 디버깅) 실행 + 에이전트 호출(PYTHONUTF8=1).
- `backend/agent_profile.json` — 본인인증 정보(gitignore, 로컬 전용).

## 자가검증 (회귀 테스트)

정부24 셀렉터/DOM 변경을 조기에 잡기 위한 도구(확장의 `selftest.mjs`에 대응):
```bash
cd backend && venv\Scripts\python.exe selftest_agent.py    # 로그인~인증 자동입력 9/9 검증
```
진짜 크롬을 띄워 로그인→Mbuster통과→간편인증→simpleCert iframe→자동입력까지 확인한다
('인증 요청'은 누르지 않음 — 실인증은 사람만). 크롬/playwright 없으면 SKIP.

## 주의

- 정부 사이트 DOM 변경에 취약(선택자 유지보수). 셀렉터는 `simpleCert` 실측 기준(2026-07).
- 자동화용 크롬은 **전용 프로필**이라 기존 로그인 세션과 분리됩니다(간편인증 새로 진행).
- 완전 무인 대리인증은 불가(본인인증 필수) — 안전·합법 설계.
