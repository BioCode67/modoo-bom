## 릴리스 설명 (그대로 붙여넣기)

```
모두봄 로컬 에이전트 — 정부 서류 자동발급·복지 자동신청을 내 PC에서.

■ 설치
1) modoobom-agent.zip 다운로드 후 압축 풀기
2) 폴더 안 '모두봄-에이전트.exe' 더블클릭
3) 브라우저가 자동으로 열립니다(http://localhost:8000). 창을 닫으면 종료됩니다.

■ 필요 환경
- Windows 10/11
- Google Chrome 설치(정부24 자동조작에 사용). 미설치 시 Edge로 폴백.

■ 할 수 있는 것
- 서류 11종 자동발급: 주민등록등본·초본, 가족관계, 장애인증명, 소득금액증명,
  지방세 납세/세목별 과세증명, 기초생활수급자, 한부모가족, 건강보험 자격득실, 고용보험 이력
- '전부 자동발급': 한 번 인증으로 필요한 서류를 순서대로 이어서 발급
- 복지 자동신청: 복지로 신청 정책을 로그인·양식작성까지 자동

■ 안전(중요)
- 개인정보는 내 PC에만 — 서버로 전송하지 않습니다.
- 카카오 본인인증과 최종 '제출'은 반드시 본인이 직접(법적·비가역 단계라 자동화하지 않음).
- 에이전트는 로그인·이동·양식 자동작성·서류 저장까지만 대신합니다.
```
