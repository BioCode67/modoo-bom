  모두봄 로컬 에이전트 — 사용법
  정부 서류 자동발급 · 복지 자동신청을 내 PC에서
================================================================

■ 실행 방법
  1) 이 폴더의  「모두봄-에이전트.exe」  를 더블클릭하세요.
  2) 검은 콘솔 창이 뜨고, 잠시 후 브라우저가 자동으로 열립니다.
     (자동으로 안 열리면 브라우저 주소창에  http://localhost:8000  입력)
  3) 종료하려면 콘솔 창을 닫거나 Ctrl+C 를 누르세요.

■ 준비물
  · Windows 10 / 11
  · Google Chrome 설치 (정부24 자동조작에 사용).
    크롬이 없으면 Microsoft Edge 로 자동 대체됩니다.

■ 할 수 있는 것
  · 서류 자동발급 (15종): 주민등록 등본·초본, 가족관계, 장애인증명,
    소득금액증명, 지방세 납세/세목별 과세, 기초생활수급자, 한부모가족,
    국세 납세증명, 출입국사실증명, 병적증명서, 건강보험료 납부확인,
    건강보험 자격득실, 고용보험 이력
  · '전부 자동발급' : 한 번 인증으로 필요한 서류를 순서대로 이어서 발급
  · 🚀 원클릭 연쇄 : '전부 자동발급' 아래 체크를 켜면 발급이 끝난 뒤
    담은 복지(청년월세지원 등)의 신청 양식 작성·서류 자동첨부까지 이어서
    진행하고 '제출 직전'에 멈춥니다(제출은 본인 확인 후).
  · 복지 자동신청 : 복지로 신청 정책의 로그인·양식작성까지 자동
  · 🗂 내 서류함 : 발급/등록된 서류 목록·자동첨부 후보 확인·개별 삭제.
    임대차계약서·신분증은 [📷 촬영]으로 찍으면 보정된 제출용 PDF로 등록됩니다.
  · 🤖 상태 스트립 : 에이전트 연결·버전·발급 슬롯 확인. [발급 전 점검]을 누르면
    자동화 브라우저·정부24/복지로 연결·발급 폴더·디스크를 한 번에 점검해요.
    문제 시 [진단 복사]로 기술 정보 복사(개인정보 없음).
  · 🔁 이어보기 : 발급/신청 도중 새로고침·화면 이동해도 돌아오면 진행 상태가
    자동으로 다시 연결됩니다.

■ 안전 (중요)
  · 입력한 개인정보는 이 PC 안에서만 처리됩니다. 서버로 보내지 않습니다.
  · 카카오 본인인증과 최종 '제출'은 반드시 본인이 직접 하셔야 합니다.
    (법적·되돌릴 수 없는 단계라 자동화하지 않습니다.)
  · 에이전트는 로그인·이동·양식 자동작성·서류 저장까지만 대신합니다.

■ 문제가 있을 때
  · 브라우저가 안 열리면: 콘솔 창에 표시된 주소를 직접 입력.
  · 자동발급이 안 되면: 화면의 공식 사이트 바로가기로 직접 발급.
  · 백신이 실행을 막으면: 서명되지 않은 실행파일이라 그럴 수 있어요.
    '추가 정보 → 실행'으로 허용하거나, 공식 사이트에서 직접 발급하세요.
